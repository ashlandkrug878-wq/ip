# 视觉证据与提示词转译

目录：覆盖；归档；逐图；跨图；三层转译；输出。

## 1. 覆盖清单

覆盖早期设定及改版、标准形象正侧背与表情、代表与日常内容、首产品／爆款／常销、不同材质系列及联名、用户使用、普通争议失败款。先确定研究意义再收集；缺角度保留空缺。相似图去重，保留图像语境。

## 2. 保存与索引

记录 image_id、subject_id、图片类型、产品系列／版本／年份、作者品牌、source_page_url、original_image_url、observed_at、权利说明与使用限制、官方或用户来源、选择理由、event_ids、product_ids。

独立记录 page_published_at、product_released_at、image_created_at，未知为null。保存状态：saved／reference_only／unavailable。可合法留存且工具支持时下载原图，记本地路径、实际格式、SHA256；失败只记引用，禁止把URL冒充已存文件。用于公开网站前单独确认图片再分发依据，不因研究用途推定公开授权。引用图不可用AI图冒充。

## 3. 逐图拆解

每张至少记录：
- observed_features：直接可见的轮廓、宽高、对称、重心、头脸额眼型眼距视线鼻嘴耳发、躯干四肢连接姿态。
- visual_language：线条曲直几何、色彩面积、细节密度留白（色板必读color-system.md）、识别锚点与临时装饰。
- official_settings：附来源的角色设定，不从画面猜官方人设。
- interpretation：形状表情动作反差 → 感知 → 表达／需求；标推断及替代解释。
- material_and_structure：表面毛长光泽缝线印刷植绒拼接、悬挂站立、接缝承重易损。官方规格与推测分列；不从渲染确定量产工艺、内部结构、尺寸。
- presentation：角度、透视、焦距感、灯光背景构图。比例为视角估计，不视为标准设定。

只有真实打开／查看图片后才能填写直接观察；缩略图不足以判断面部印刷或工艺时写清楚。

## 4. 跨图设定

至少多个版本对照，分身份不变量、表达不变量、系列变量、载体适配、待核实项。说明哪些只在本样本成立；不要把黄色、兜帽、服装等单款现象武断视为全角色绝对规则。

## 5. 三层提示词

开头声明：以下为依据可见作品的研究重建，并非创作者原始提示词，不能证明作品由AI制作。

### 第一层：研究性样本描述

只描述所见角色本体 → 当款材质 → 拍摄呈现，用于归档检索与理解。研究报告正文可命名对象；可执行出图文本不带现有IP、品牌或艺术家名称。禁止补画不可见结构。

### 第二层：机制卡

可见特征 → 产生感知 → 表达／需求 → 内容或产品作用 → 证据／image_id → 替代解释及边界。不能将“更萌”当作已证明促购。

### 第三层：原创转译

先重新定义原点、态度、目标用户、使用场景及首产品，再设计独立的轮廓、比例、五官配置、标志特征及色彩关系。原对象换色、换装、换道具不足以完成原创转译。借用情绪传递机制，不借用专属识别组合。

输出六条文本，形成三组中英配对：
0. 黑白找形 zh/en：遵循creative-handoff.md，禁止颜色、材质和灯光；用于原创转译的身份建立。
1. 平面设定 zh/en：主体、比例轮廓、五官定位、固定识别、动作、线条与色块；白底清晰正面；不混入摄影材质。
2. 实物概念 zh/en：相同身份、明确SKU与尺寸目标、材料部位、结构简化、制造约束、摄影；未打样标概念而非量产结论。

分开写固定项、系列变量、材质工艺、画面呈现和排除项。用具体可见语言替代“高级、治愈、潮玩感”。本工作流默认包含拟发布提示词所需的实际出图验证；单纯事实调研、无可执行提示词时不为凑流程生成。用户仅要未测草稿或禁止生成时遵从，但标未测，不能进入已验证正式区。

### 正式提示词发布前的实测关卡

按“目标锁定 → 草稿 → 实际生成 → 看图对照 → 差异清单 → 修词重测 → 接近后发布”执行，不把自信或文字详尽当作通过。

1. **锁定目标。** 从实际网页定位待测原文和章节，记录对象、基础版／具体SKU／历史版本、平面／实物载体及参考image_id。没有可靠标准图时标研究重建，不把单款服饰或多版本拼合当作官方母版。原创示例单列，不能顶替被研究IP的基础词。无需让用户重复提供自己已交付网页中的文本。
2. **实测发布版本。** 平面、毛绒、手办等不同文本分别生成；中文实测不等于英文已测，另一语言也测或标未测。纯文字模式不附图；依赖参考图的模式记录图片并在网页提示。修词后须用新全文再生成，不能改词后沿用旧图宣称有效。跨载体引用母版如实记录依赖，不当作独立文字验证。
3. **看图对照。** 与原始目标／同一母版逐项比较：整体轮廓与头身、额脸眼型眼距鼻嘴、主辅色明度饱和度及区域、标志组合、部位材质结构、动作构图。记录接近／有明显偏差／无法判断及具体观察。颜色对但身份轮廓错仍不通过；不能用主题道具遮掩基础形象偏差，不用主观分数冒充测量。
4. **自我修正。** 点明偏差及文本诱因，如内折角变卷尖、橙脸变白脸、一体角色变戴帽人。优先修轮廓、比例、五官、色彩，再修表面细节；保留已接近项，补具体部位、相对尺寸或必要排除项，重新生成查看。不得擅改目标来迎合结果。仍偏离时保留缺口，不自动降低标准。
5. **验收和网页写入。** 所有关键身份、轮廓、五官、色彩项均可判断且接近，对应载体无明显材质结构错误，才能标ready。标清剩余轻微差异，不能宣称精确复刻或量产通过。正式区展示最终实测词、对应图、模式与参考图依赖。旧失败词与图只放折叠“测试记录／未通过”；未测新词不进正式可用区。词或依赖发生实质变化后须重测。

记录每版prompt_id、version、subject_id、target_scope、carrier、exact_prompt、language、input_mode、reference_image_ids、生成图路径、逐项观察、修订原因、tested_at、status。status用draft／testing／revise／blocked／ready。这是内部质量状态，不另加用户批准步骤，也不替代用户此前对GitHub公开上传的确认。

## 6. 交付

视觉索引＋代表产品图录＋逐图拆解＋不变量变量表＋视觉—表达—需求映射＋三层文本＋待人工检查的相似性及工艺风险＋缺图清单。每个结论回到image_id，每张图回到来源。

## 社媒配图身份检查

介绍笔记中的配图先按官方原图／用户实拍／二创／概念图／身份未知分类。没有图源说明时，不因它配在IP介绍文章里就认定为官方标准形象。与至少一个官方角色或产品样本对照：面部配置、比例、标志组合是否一致。无法确认的留作线索，不用于锁定技术设定；不凭观感断言它是AI生成。
