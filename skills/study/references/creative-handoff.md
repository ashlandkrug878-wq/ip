完整调研必读。参考仓库 ashlandkrug878-wq/ip 的当前Markdown结构，但把仓库对标速记作为检索线索，不能当外部事实。研究规则允许被新证据修正。

## 研究缺口对照

| 创作端需要 | 研究必须取得 | 交付字段 |

| lab：表达 | 场景、行为、状态、矛盾、没说出口的话；圈层、既有消费、符号黑话、晒法、付费／破圈 | audience_insights；每个层次分别标直接证据与解释 |
| form：五轴 | 原型、整体轮廓、记忆点、五官、情绪范围；反常点与线条语言 | form_spec；不能用“1.5头身＋治愈”代替关系 |
| form：头脸 | 头型、发型、发色、耳、头饰、突出物、眉、眼型、眼距、视线、眼部附加、鼻、嘴、脸颊、肤色、标记、表情可变性 | head_face_profile；可无、不适用或未知 |
| form：结构 | 头脸横纵、眼脸关系与留白、体块层级、四肢连接、支撑／重心、挂点、遮挡、侧背面 | form_spec；比例估计注明视角，不假装测量 |
| form：识别 | 记忆复述、剪影、简化、缩小、换皮／去可拆道具、头像裁切 | recognition_checks；观察／实测／用户测试分级 |
| studio：配色 | 主色、签名候选、辅色、中性色、五官线色、点缀；主体与背景分开 | color_system；详见color-system.md |
| studio：材料 | 部位—基材—表面—五官制作—连接—触感—动作功能 | material_map；图片观察／官方规格／采访口径分开 |
| studio：内容 | 住哪、每天做什么、想要、害怕、与用户关系；配角与族群；口头禅 | narrative_system；官方／研究归纳／未知分开 |

| 验证 | 真实行为、反例、失败、预约／定金／购买／复购、退坑 | validation_evidence；曝光、点赞、稀缺不代成交 |
| 时代 | 当时与今天的平台、渠道、成本、审美、组织资源差异 | transfer_boundary；历史解释与未来建议分别写 |

## 关键防错

- 签名色、固定微笑、头身比、材料优先序、创作周期、粉丝门槛等不能直接从仓库模板反推每个案例事实。
- 单角色与族群IP的识别约束不同。先判断是一个人换装，还是多个成员共享视觉语法。
- 公共／代表性组合／反常标签描述相似性，不判断元素所有权；不规定必须在头顶加装饰。
- 内容丰富是否带来长生命周期、艺术家签约是否等于收购、颜色是否跨系列不变，都要以证据检验。
- 不根据研究自动改选品板、用户批注、锁定角色及素材池；方法卡先提出，需用户选择后进入创作。

## 六类文本交付

样本描述用于归档，不默认用于生成原角色。原创转译另定独立身份，分三阶段中英文本：
1. 黑白找形：轮廓体块、头脸几何、表情姿态、记忆点连接、正面全身、剪影角标；不写色彩材质灯光。
2. 平面上色：固定上述身份，色板分区、线稿色、主体与环境区分，不重新找形。
3. 实物概念：固定身份与色块，按部位写材质、工艺和结构，最后机位灯光；标未打样。

已有参考图则按参考锁形；没参考时标文字设定待验证。均不包含现有IP、品牌或艺术家名。研究文本和原创文本分开，不能把拆出的原角色提示词悄悄换色冒充原创。
