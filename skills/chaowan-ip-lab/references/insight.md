# 洞察与圈层：内核从哪里来

1.0 的问题是先有形象再补表达，表达容易空。1.1 规定顺序：**先观察到一个人群的真实状态，再从状态里长出表达，最后才做外形。** 这份文件写的是怎么观察、怎么写、怎么判断写得够不够深。

## 1. 情绪洞察：五要素

每个方案在表达之前，都要先写一段洞察，包含五个要素，缺一不可：

| 要素 | 写什么 | 例 |
|---|---|---|
| 场景 | 在哪里、什么时候 | 晚上十点，还在工位上 |
| 行为 | 观察到他们在做什么（行为，不是情绪形容词） | 把工位摆满毛绒，开会时捏着一个捏捏 |
| 状态 | 这个行为背后的真实状态 | 不是开心，是在一个没法离开的地方给自己造一个能喘气的角落 |
| 矛盾 | 他们身上互相拉扯的两股力 | 想逃离，又不能也不敢真的离开 |
| 没说出口的话 | 他们心里有、但不会公开说的一句话 | 我不是爱这里，我只是需要在这里活下去 |

"没说出口的话"往往就是表达的雏形。表达可以比它更轻、更可爱，但不能偏离它。

**证据要求**：场景和行为要有来源（趋势报告、新闻、榜单、社交平台现象、用户给的内部数据），并在方案里注明。没有证据的洞察要标"推测"。

## 2. 三层深度检查

写完洞察后自查它停在哪一层：

- **表层：情绪标签**。"年轻人很焦虑""大家想被治愈"。人人都知道，不构成洞察
- **中层：具体需求**。"打工人需要在工位上解压"。有用，但别人也能想到
- **深层：矛盾和没说出口的话**。"想逃又不能逃，于是把牢笼布置得可爱一点"。这一层才有独特性

方案的洞察必须到达深层。停在表层或中层时，回到第 1 步继续追问"为什么"，一般追问两三次能到深层。

## 3. 好洞察与坏洞察

**坏**：现代年轻人压力大，需要情绪价值，所以做一个治愈的形象。
问题：只有情绪标签，没有场景和行为，没有矛盾，任何治愈系 IP 都能套。

**好**：考试周的大学生在图书馆通宵，桌上放着一只小玩偶，拍照发朋友圈配文"陪我熬"。状态是孤独地努力，希望有人看见但不想被打扰。矛盾是想被陪伴，又不想有人真的来说话。没说出口的话："你在就好，别说话。"
→ 表达可以是"我就在旁边，不出声"。

## 4. 圈层画像模板

洞察对应的人群要具体到圈层，每个方案写一份画像：

- **圈层名称**：他们自己会怎么称呼自己
- **是谁**：年龄段、身份、城市层级
- **聚集在哪**：平台、线下场所、社群
- **已经在买什么**：现在为这个状态花钱买的东西（这是验证需求真实存在的最好证据）
- **符号和黑话**：他们之间通用的词、梗、颜色、手势，用来做圈层彩蛋
- **怎么晒**：买了以后会怎么拍、发在哪、配什么文案。晒不出去的产品很难传播
- **付费力和频次**：大概的价格接受度
- **破圈路径**：从这个圈层传到路人的方式

## 5. 常见圈层清单

不是完整列表，只作为起点；每期都应该根据新信号补充：

- 打工人（工位、通勤、加班、年终）
- 考试党、学生党（期末、考研、图书馆）
- 独居者（一人食、一人游、替代性陪伴）
- 宠物党，猫派和狗派分开看
- 情侣与暧昧期（送礼、纪念日）
- 二次元与谷子圈（吧唧、痛包、摆阵）
- 服饰圈：洛丽塔、JK、汉服
- 追星饭圈（应援色、应援物）
- 户外与运动圈（徒步、骑行、飞盘）
- 玄学与祈福圈（转运、许愿、寺庙文创）
- 抽象与发疯文学圈（自嘲、反讽、荒诞）
- 隐私与断联圈（数字排毒、关掉手机）

## 6. 一个洞察可以服务几个圈层

好的洞察往往不止属于一个圈层。写完画像后，问一句：这个矛盾在别的圈层里是否也存在？如果存在，就是破圈的线索。例如"想被陪伴又不想被打扰"同时存在于考试党、独居者和打工人里。
