## 1. 洞察层：观察到了什么（新增）

**1.1 观察到的状态**：场景加行为加状态，要有来源。不是情绪标签，而是"在什么场景里、做了什么、背后是什么状态"

**1.2 矛盾**：互相拉扯的两股力。想逃又不能逃；想被陪伴又不想被打扰；想被看见又怕被评判；想躺平又焦虑

**1.3 没说出口的话**：圈层心里有、但不会公开说的一句话。表达从这里长出来



## 2. 内核层：它是谁

**2.1 表达**：它对世界的一句态度。必填，在外形之前确定，从洞察层的"没说出口的话"长出来。五种句式：
- 允许型：给一种被嫌弃的状态松绑。例：哭不丢人；慢一点也没关系；不想努力了
- 反差型：外表和内在相反。例：不乖也可以被爱；坏女孩也有少女心；再坏也是家人
- 陪伴型：我在你身边。例：小小的我也能照亮别人；我是你的好朋友
- 留白型：不定义，让用户自己填。例：不定义情绪，只承载情绪；我是一块画布
- 自嘲型：用玩笑消化压力。例：996 配咖啡杯；熬夜的我也很可爱

**2.2 情绪基调**：第一眼的情绪。治愈、调皮、冷酷、忧郁、慵懒、元气、迷糊、平静、诡萌、松弛

**2.3 人设关系**：单人 / 对手搭档（美乐蒂与酷洛米）/ 情侣（线条小狗）/ 群像（Chiikawa）/ 家族

## 3. 圈层层：为谁做（新增）

**3.1 目标圈层**：具体到他们自己会怎么称呼自己。打工人、考试党、独居者、猫派、谷子圈、洛丽塔、户外、玄学祈福、抽象发疯文学、断联派等（清单见 `insight.md`）

**3.2 圈层符号**：他们的黑话、梗、颜色、手势、物件，用来做彩蛋和命名

**3.3 晒法与社交场景**：买了以后在哪里晒、怎么拍、配什么文案；晒不出去的产品很难传播

## 4. 内容层：它在哪里被看见

第一步只定方向：主载体、次载体和一个经典动作种子。动作库、表情包、故事在第二步细化。

**4.1 内容出身**：绘本、网络漫画、表情包、动画、电影、艺术家作品、品牌吉祥物、乐园人偶、明星特质

**4.2 主要载体**：实物潮玩、视觉海报、表情包、漫画绘本、动画影视、乐园线下、品牌场景、授权周边、短视频直播

**4.3 次要载体**：同上，通常和主载体互补（实物配海报，表情包配联名）

载体决定设计重点：
- 实物潮玩、海报 → 造型、招牌姿势、手感
- 表情包、短视频 → 经典动作、表情丰富度、线条简单到能大量绘制
- 授权周边 → 极简、能印在任何东西上
- 动画影视 → 性格和剧情

短视频直播作为主载体目前是空位，适合以"能一直演"为核心来设计。

**4.4 经典动作**：动起来时反复出现的标志行为。送心心、气呼呼跳脚、跳舞、哭、发呆、捂脸、翻白眼、躺倒

## 5. 外壳层：它长什么样

**5.1 原型**（6 类）：
- 人：夸张比例但仍是人（MOLLY、CRYBABY）
- 类人：人形，加一个非人的头套或元素（星星人、YOYO、HACIPUPU）
- 动物：保留动物形态（布丁狗、线条小狗）
- 动物类人：动物外形，直立、穿衣、有人的行为（Kitty、玲娜贝儿、奶龙）。最大的一类，兼顾亲近感和情绪承载
- 怪兽精灵：现实里没有的生物（LABUBU、史迪奇）
- 拟物食物 [反常]：物件、食物、植物、天气（蛋黄哥、雪王、孢绒绒）

**5.2 物种**（动物类）：狗、猫、兔、熊最热，也最能吸引宠物人群；其次龙、狐狸、鸭、鱼、外星生物。冷门物种 [反常]

**5.3 头身比与体型**：1 / 1.5 / 2 / 2.5 / 3 头身；团子、豆子、婴儿体、圆胖、梨形、方块 [反常]、细长 [反常]。原则：要"不像人"，同时要简单

**5.4 记忆点**：闭眼后会记住的那一个。牙、眼泪、嘴、耳朵、头饰、头套、长出来的东西、整体轮廓。只能一到两个

**5.5 记忆点位置**：头顶、脸部（首选，33 个对标 IP 里 26 个在这里）、整体轮廓、身体功能件（只有承载功能或故事时才成立，比如能掏东西的口袋）

**5.6 表情**：无表情、嘟嘴、坏笑、哭、眯眼、发呆、歪嘴、惊讶

**5.7 招牌姿势**：静止时一看就认得出的姿态。歪头、双手虚握（可以塞东西，利于二创）、背手、叉腰、抱膝、抱东西

**5.8 换装方式**：换衣服、换头套、换材质、换场景、扮演别的东西（mofusand 式）

**5.9 命名**：
- 叠音型：LABUBU、YOYO、WAKUKU、孢绒绒。好念，像叫小孩小名
- 描述型：星星人、奶龙、草莓熊、线条小狗。一听就知道长什么样，传播成本最低
- 人名型：MOLLY、Kitty、美乐蒂。老 IP 居多
近两年的新 IP 多用叠音型和描述型

## 6. 视觉层：它的气质

**6.1 配色**：白底加一个签名色（三丽鸥式）/ 单色识别（史迪奇蓝、草莓熊粉、奶龙黄）/ 马卡龙 / 低饱和莫兰迪 / 复古暖调 / 暗黑加一点亮色 / 镭射渐变 [反常]。原则：颜色是变量，签名色是常量

**6.2 细节密度**：极简（便于二创、授权、表情包，对标 IP 里约三分之二）/ 中等 / 繁复（收藏向，如 SKULLPANDA、HIRONO）

**6.3 手感**：长绒、短绒、仿貂绒、软搪胶、硬 PVC、植绒 [反常]、透明果冻 [反常]、针织

## 7. 商业层：怎么做成产品

第一步只定方向和价格带，并标出明显的工艺风险。工艺转译、打样、稀缺机制设计、投产验证在第二步。

**7.1 主品类与材质**：搪胶毛绒挂件（头部搪胶保细节，身体毛绒降成本，可以在盲盒和毛绒之间穿梭，首选）、毛绒公仔、PVC 盲盒、大娃、BJD、表情包、授权联名

**7.2 尺寸与价格带**：几十元挂件是社交货币 / 百元左右盲盒是自我奖励 / 数百元大娃是收藏和送礼

**7.3 稀缺机制**：隐藏款概率、限定款、节日款、城市限定、会员专享

**7.4 玩法**：收藏、挂包社交、二创、陪伴、送礼许愿、追星式人偶互动、数字心情（WAKUKU 式）

**7.5 生肖与节点**：2027 羊年、2028 猴年；情人节、圣诞、生日。形象本身不是该动物时，可以用可替换的头套或头饰承接生肖（HACIPUPU、Sonny Angel 式）

## 8. 时机层：它为什么在这个时候火

**8.1 推出时的主流**：甜美治愈 / 暗黑酷 / 丑萌怪趣 / 软萌治愈（详见 `rules.md` 审美钟摆）

**8.2 反差位置**：对面（稀缺，风险高回报高）/ 同侧（跟风，靠渠道和速度）/ 细分圈层（避开正面竞争）

**8.3 时代情绪**：焦虑、疲惫、躺平、想被治愈、想发泄、想被看见、想被允许

## 9. 前瞻层：超前一步（新增）

**9.1 前瞻色彩**：年度色、季度关键色。年度色人人会用，建议当签名色或反差色，不要直接当主色

**9.2 前瞻材质**：面料和工艺趋势，转译成潮玩工艺（对照表见 `foresight.md`）

**9.3 前瞻风格与消费者**：新的审美方向和未来消费者画像，和审美钟摆对照判断方向

每条前瞻信号都要标时间窗（现在 / 6 到 12 个月 / 12 到 24 个月）和可信度（A 机构官方 / B 行业媒体 / C 软文赞助）
