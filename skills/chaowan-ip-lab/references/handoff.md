# 交接：IP 档案

用户选中某个方案（说"就这个""保留""进入下一步"，或在选品板标记保留）后，生成这份 IP 档案。它是第一步交给第二步（chaowan-ip-studio）的唯一文件，第二步所有模块都以它为依据，并在每个模块完成后更新它。

生成规则：
- 内容全部来自已经写好的方案卡，不要在交接时新增设定
- "不变量"一节要写得具体到可以检查（例如"头顶番茄红火苗形火气团"，而不是"头顶有个元素"）
- 第一步没有定的内容（经典动作库、口头禅、故事线、工艺）留空，写"待第二步补充"
- 作为 Markdown 文件交付，文件名：`IP档案_<名字>_v1.md`

```markdown
# IP 档案：<名字>（<英文名>）
版本：v1 · 来源：<第 N 期方案 X 或用户指定原点> · 日期

## 不变量（任何模块都不能改）
- 表达：
- 记忆点：
- 轮廓与头身比：
- 签名色：
- 核心性格：

## 内核
- 洞察：场景 / 行为 / 状态 / 矛盾 / 没说出口的话（附来源）
- 圈层：是谁 / 在哪 / 已经在买什么 / 黑话符号 / 怎么晒 / 破圈路径
- 时机站位：
- 用到的前瞻信号：

## 外形
- 原型 · 物种 · 体型 · 招牌姿势 · 命名
- 头部元素（逐项，带公共、专属、反常标签）
- 主色 · 细节密度 · 手感
- 基础形象出图提示词（中英文）

## 内容（待第二步补充）
- 主载体 · 次载体
- 经典动作（第一步给的种子）：
- 口头禅与常用文案：
- 关系与世界观：
- 故事线：

## 变量（可以随系列变）
- 服装 · 配色 · 场景 · 材质 · 联名

## 产品（待第二步补充）
- 首发品类方向 · 价格带 · 稀缺机制 · 可借的节点
- 第一步发现的工艺风险：

## 来源链接
- 洞察和原点的原文链接

## 变更记录
- 日期 · 模块 · 改了什么 · 为什么
```
