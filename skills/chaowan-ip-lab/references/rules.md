## 1. 组合规则

1. **先有洞察，再定表达，最后选外形。** 表达从洞察的"没说出口的话"长出来，其他维度围绕表达选
2. **锁定加随机。** 用户锁定的维度不动，只在其余维度里变化
3. **识别来自组合关系。** 可用熟悉原型加意外变化，也可靠头脸比例、轮廓、留白和姿态形成身份。特殊附件不是必需品
4. **控制焦点。** 通常一到两个主要视觉焦点，其余支持它；不按反常标签数量判定质量，也不强制反常
5. **纹理服务识别。** 重复孔洞、鳞片或毛流不能遮盖脸部；装饰是否舒适须看实际图，不能靠文字自动判定
6. **交付可执行的头脸设计。** 写清轮廓、眼型、五官位置和留白关系，不能把“豆豆眼＋腮红＋微笑”作为每个角色的默认脸
7. **从整体找记忆点。** 头脸、身体比例、动作和功能结构都可以，不为满足规则在头顶加物
8. **检查大中小体块。** 简单或繁复都要有层次。毛发和灯光不能掩盖薄弱的造型；详细规范见 `form-and-prompts.md`
9. **方案之间要拉开。** 同一次输出的多个方案，在圈层、句式、原型、钟摆位置上不要扎堆

## 2. 兼容、冲突与禁止

**加分组合**
- 暗黑画风 + 马卡龙色（反差萌）
- 慵懒情绪 + 圆胖或团子体型
- 极简造型 + 留白型表达（便于二创）
- 双手虚握或抱东西的姿势 + 表情包或短视频载体
- 动物类人 + 宠物人群 + 生肖节点

**常见工艺冲突**（第一步只做提示，详细的工艺转译在第二步）
- 毛绒 + 细框眼镜、雀斑、发丝、精细表情 → 改为搪胶头部，或简化为刺绣、印花
- 繁复细节 + 授权周边载体 → 简化
- 结构复杂（多零件、多模具）+ 首发验证期 → 成本排序是造型结构 > 零件 > 颜色

**禁止项**
- 大面积重复纹理放在脸上（鱼鳞、密集斑点、孔洞），容易引起密集恐惧或病变联想
- 照搬某个 IP 已经占住的专属元素（尖牙、眼泪、无嘴加蝴蝶结、星星兜帽）
- 出图提示词里写现有 IP、品牌或艺术家的名字
- 直接用奢侈品牌等真实商标做造型元素（需要授权）

## 3. 五项测试

分开记录证据阶段：
- 只有文字：五项均标“待出图验证”，列具体风险和验证方式，不写“通过”。
- 有实际图：记录图和版本，按可观察证据给“通过 / 存疑 / 不通过”；未制作或查看的变体标“未验证”。不可假装做过闭眼、缩图或换皮实验。
- 技术和设计检查不等于用户的保留、淘汰或商业判断。

1. **记忆点复述**：看图能描述哪个轮廓和情绪？标为观察判断，不伪称真人记忆实验。
2. **剪影**：实际黑色轮廓中，头、身体和突出物是否仍有区分？
3. **简化**：概括线条能否保留识别？复杂收藏型不强求三五笔，检查删掉次要细节后能否读懂。
4. **缩小**：实际查看缩图；屏幕识别不等于已验证 5 厘米实物或生产工艺。
5. **换皮**：改变服装或材质仍有身份吗？另加去可拆道具检查；拟物或功能角色保留身份结构，不拆掉铜钱的方孔或功能角色的长臂。

## 4. 审美钟摆

头部 IP 的爆发，几乎都站在上一波主流的对面：

甜美治愈（MOLLY、DIMOO）→ 暗黑酷（SKULLPANDA，在一片甜美里显得稀缺）→ 丑萌怪趣（LABUBU）→ 软萌治愈（星星人、YOYO，2025 至 2026 年）→ 下一次摆动（推测：荒诞、抽象、怪趣、好玩的不完美；疗愈转向"允许退出"）

使用方法：结合 `foresight.md` 的前瞻信号，判断当下哪种风格已经饱和，评估往反方向走的机会。这是规律推断，不是确定结论，给用户建议时要说明。

## 5. 两层用户与圈层彩蛋

- **表层给路人**：好看、情绪普适，不需要背景知识就能喜欢，负责破圈
- **深层给圈层**：藏只有懂的人才读得出来的东西，负责忠诚
- 彩蛋载体：一句话（系列名、口头禅、文案）、一个道具、特定配色、手势、数字或日期、名字本身
- 彩蛋要用圈层自己的符号和黑话（见圈层画像）
- 标准：不懂也不影响喜欢，懂了会更喜欢

## 6. 质量门槛

不给方案打分，也不排名次：审美取舍和保留淘汰由用户决定，AI 仍须指出结构、执行和辨识问题。交付前自查下面几条，没过的回去重写：

- **洞察到达深层**：写出了矛盾和没说出口的话，不是情绪标签
- **有来源**：场景和行为附了原文链接；没有来源的标"推测"
- **圈层具体**：写得出他们已经在为这个状态买什么
- **造型规格完整**：有轮廓、脸部几何、体块和结构连接；不是通用萌物加符号
- **材质支持造型**：区域和工艺清楚，纹理不遮脸；不把写实纹理或渲染精度当设计质量
- **证据诚实**：没有图不宣布五项通过；有图按对应证据记录，不自动更新用户选择
- **没撞车**：和对标库里的 IP 拉得开
- **没碰禁止项**

## 7. 只按用户的选择学习

批量模式下，偏好方向只根据用户的选择调整，不把 AI 的检查结果当作用户喜好；造型、执行和结构检查仍须完成：

- **读三样东西**：上一期每个方案的状态（保留、待优化、淘汰）、用户的批注、用户的原点池
- **批注最优先**：用户写了"喜欢 X""不要 Y"，直接作为下一期的约束，并在交付时说明是怎么照着改的
- **保留**：不再重复出现，生成 IP 档案，提示进入第二步；它的洞察类型、圈层、句式、原型记为用户偏好的方向
- **待优化**：下一期出一个优化版，写清和上一版的差别；有批注时按批注改，没有批注时只改最弱的一两处，并说明改了什么
- **淘汰**：同类方向（同一个洞察、圈层或原型组合）下一期不再出现；被淘汰两次以上的方向，除非有新的强信号，不再出现
- **没标记的方案**：不当作喜欢，也不当作不喜欢，不据此调整
- **原点池**：池里的原点作为下一期的候选原点，优先考虑；用户在批注里对它有意见的（例如"原点保留，具像化重做"），按意见处理
- **色系池、单色收藏、材质池不用于第一步**：它们是第二步配色和选材的素材库，第一步只负责抓取颜色和材质、整理成表和推荐色系供用户存
- **批注里说要存的东西**：用户在批注里写"这个原点可以存""这个颜色留着"时，照做存入对应的池，并按批注里的其他意见处理
- **原点只收外部信号**：用户的评价不是原点，不要写进原点清单
- **保留探索**：约三分之二的方案向用户的选择倾斜，约三分之一保留新方向，交付时说明哪些是探索
