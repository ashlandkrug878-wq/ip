# 潮玩 IP 找形 v2.0 · 工作流第二步

**这一步只做一件事：给一个表达找到对的形。** 分两段：

| 段 | 出什么 | 用户做什么 |
|---|---|---|
| **发散段** | 6 张完整概念图（产品照），形、色、材一起出 | 挑方向：保留、待优化、淘汰 |
| **锁形段** | 以挑中的概念图为参考图，出白模和线稿（带剪影角标），必要时裂变 4 个 | 确认剪影和体块，锁定 |

为什么这样分：用户挑选看的是物件怎么长进身体、一处特殊材质和配色。白模和线稿把这三样都去掉了，所以从白模开始找形，出来的都普通；反而是一次把形、色、材出全的日更概念图更像潮玩。白模和线稿留到锁形段，用来检查剪影、体块和站不站得住，并给第三步当三视图和打样的依据。"先形后色再选材"是生产顺序，不是发想顺序。

原则：
1. **从用户的选择里学，不从现有 IP 的平均样子里学。** 默认方向按 `form-and-prompts.md` 第 1 节：生物 + 物件长成身体 + 一处特殊材质 + 两三色强对比 + 收着的小五官。研究库只用来做撞车检查
2. **每轮先读 `data/feedback/learned-rules.json`。** 状态为"持续避错建议""持续正向信号"的条目变成检查清单；交付时写明对上了哪几条
3. **表达先于特点，但形不是表达的插图。** 每个形说清它怎么把表达"长"出来，表达落在物件和一张收着的脸上，不靠动作和场景去演
4. **拉开再收拢。** 第一轮在大方向上拉开，裂变只在选中的方向里微调
5. **AI 生成，人挑选。** 不打分、不排名；AI 只指出结构、辨识和工艺上的问题
6. **没看到图不下结论。** 只有文字时五项测试都写"待出图验证"

## 输入

- **标准输入**：仓库 `data/ips/<方案 id>.json` 里的表达卡，用户在选品板上标了保留（或在对话里说选中）。同时读 `data/reviews/<方案 id>.json` 的批注
- **用户直接给**：一句表达加一点背景（谁、什么情绪）也可以开始；先补一张最小表达卡：表达、句式、圈层、情绪范围、主载体，并说明是补的
- **已有形象图要改**：不是这一步。说明属于第三步的诊断模块，建议用 chaowan-ip-studio

## 流程

**第 0 步：读历史。** 读这个方案在 `data/forms/` 下已有的形，以及每个形在 `data/reviews/` 的状态和批注。被淘汰的方向不再出；批注直接变成约束，并在交付时说明怎么照着改的。

**第 1 步：列约束。** 从表达卡里抄出不能动的东西：表达、句式、表达的情绪、脸上的情绪（可以 / 不可以）、它的状态、原点转译和结构种子、圈层、主载体、用户锁定的点。脸上的情绪决定第④⑤轴能走多远（见 `axes.md`）。旧表达卡只有一个"情绪范围"和"它在做什么"时，先按 lab v2.1 补成两栏情绪和"状态"，说明是补的；"它在做什么"是动作时，翻译成状态，不照着画动作。

**第 2 步：排轴矩阵（第一轮）。** 按 `axes.md` 先为表达列 6 到 10 个能长进身体的候选物件，再给 6 个形各定七条轴和配色，画成一张表，检查拉开规则和范式配额：至少 4 个有物件融合、人形或类人最多 1 个、不出"普通动物 + 道具"、物件融合至少 4 种、特殊材质至少 4 种。表过了再往下写。

**第 3 步：写规格。** 每个形按 `form-and-prompts.md` 写最小造型规格：比例、头型、五官、身体与姿态、物件融合、材质与配色、识别组合。比例用倍数写；情绪只在静态里表达。一轮里至少 2 个不是立正。

**第 4 步：检查。** 按 `checks.md` 做撞车检查、外壳与内核、禁止项和潮玩感自检，再对一遍 `learned-rules.json`；五项测试写风险，标"待出图验证"。

**第 5 步：写概念图提示词。** 按 `form-and-prompts.md` 的发散段模板，中英文同义：一句话里同时定物件融合、比例、脸、姿态、一处特殊材质和配色，产品照，浅灰背景。负面词整段带上，再加这个形最容易画错的两三项。不写任何现有 IP、品牌或艺术家的名字。

**第 6 步：输出与写入。** 用下面的形卡格式输出；有仓库时写入（见"写入仓库"）。最后两三句话说明 6 个形之间的取舍，不排名次。

## 锁形段

用户把某个形标保留（或说"就这个方向"）后：
1. **出白模和线稿**：以这张概念图为参考图，按 `form-and-prompts.md` 的锁形段模板出白模和线稿，带右下角剪影。看剪影、体块、站不站得住，按 `checks.md` 做五项测试并写依据
2. **需要时裂变 4 个**：同样以概念图为参考，出 4 张概念图变体。原型、整体轮廓、物件融合方式不动，变物件细节、特殊材质、配色、五官或姿态，建议 1 个推夸张、1 个换材质、1 个换配色、1 个动五官或姿态。每个写一句"和母版差在哪"。挑中的变体再回到第 1 条出白模和线稿
3. 用户标"待优化"并写了批注的形，按批注出一个修订版，只改批注提到的地方；写了"更夸张""不够可爱"时，优先推大物件的尺度和反差

## 锁定

用户说"锁定""定了"时：
1. 读 `handoff.md`，生成 `ip-archives/IP档案_<名字>_v1.md`。不变量写进这个形的轮廓、头身关系、物件融合方式、记忆点、五官配置和核心情绪；概念图里的特殊材质和配色写进"候选配色与材质"，第三步定型时确认后才成为不变量
2. 概念图、白模、线稿都是第三步的参考图，档案里写明路径
3. 在形的数据里把 `locked` 设为 `true`，提示进入第三步 chaowan-ip-studio

## 形卡格式

```
### 形 <轮次字母><序号>：<一句话概括这个形>

| 轴 | 取值 |
|---|---|
| ① 原型 | |
| ② 整体轮廓 | |
| ③ 记忆点 | 位置 · 是什么 |
| ④ 五官 | |
| ⑤ 情绪表达 | 静态：眼皮、视线、嘴、重心 |
| ⑥ 物件融合 | 什么物件、成为身体哪一部分 |
| ⑦ 特殊材质与配色 | 主体材质 + 一处特殊材质；主色 + 对比色 |
| 姿态与手脚尺度 | 立正、张臂、举手……；手脚放大或缩小 |
| 头型 | |
| 反常点 | 0 到 2 处，最好是尺度或属性反差；没有写"无" |

**怎么长出表达**：这个形为什么能说出那句话（一两句）
**识别组合**：3 到 4 个具体的关系（物件、比例、颜色位置）
**造型规格**：比例 / 头型 / 五官几何 / 身体与站姿 / 结构连接（按 form-and-prompts.md）
**裁切检验**：只剩头像时靠什么认出它（记忆点在头上时写"记忆点在头部"）
**撞车检查**：最接近的现有 IP 和差别
**潮玩感自检**：八问各一句（按 checks.md）
**对上的反馈规则**：learned-rules.json 里的哪几条
**五项测试**：待出图验证，各写一个最可能的风险
**提示词**：发散段概念图中文一版、英文一版；锁形段再写白模和线稿
```

## 写入仓库

仓库 `ashlandkrug878-wq/ip`，规则见仓库根目录 `AGENTS.md`：
- 每个形写一个文件 `data/forms/<方案 id>-<轮次字母><序号>.json`，例如 `data/forms/2026w42b-1-A3.json`。字段见 `references/form-and-prompts.md` 末尾
- 运行 `python scripts/build_index.py` 和 `python scripts/build_queue.py`（会给每个形加一个出图任务；任务类型和文件名沿用 `lineart`、`lineart-01.webp`，发散段的概念图也存这个路径，网站不用改；锁形段的白模和线稿在形的数据里写 `lock_images` 路径），一起提交推送
- 用户在选品板网站「找形」一栏挑选和上传图；不要改 `data/reviews/` 里用户写的东西
