# 潮玩 IP 找形 v1.2 · 工作流第二步

**这一步只做一件事：给一个表达找到对的形。** 输入是表达，输出是一组可以并排比较的潮玩造型方向，默认出白模（统一哑光白的素模渲染，只有眼和嘴是黑色），也可以出黑白线稿；用户挑中一个、微调、锁定，生成 IP 档案交给第三步。

为什么单独一步：形还没找对就上颜色和材质，画面会被质感撑起来，看不出造型本身好不好；一个表达只出一张图，AI 给的往往是最平均的解。所以这里只看形，而且一次看很多个。

原则：
1. **表达先于特点，但形不是表达的插图。** 每个形都要说清它怎么把表达"长"出来，但表达只落在一个结构特征和一张收着的脸上，不靠动作和场景去演。研究库 12 个 IP 没有一个在演自己的表达
2. **先是潮玩，再是方向。** 6 个形都要先过 `form-and-prompts.md` 第 1 节的潮玩造型范式：能稳稳站在桌上、大头短身、体块厚实、细节少，主记忆点在头上
3. **只看形，不看质感。** 不写颜色、材质纹理和渲染精度；白模只用均匀的光看清体块
4. **拉开再收拢。** 第一轮在大方向上拉开差异，第二轮只在选中的方向里微调
5. **AI 生成，人挑选。** 不打分、不排名；AI 只指出结构和辨识上的问题，保留还是淘汰由用户决定
6. **没看到图不下结论。** 只有文字时五项测试都写"待出图验证"

## 输入

- **标准输入**：仓库 `data/ips/<方案 id>.json` 里的表达卡，用户在选品板上标了保留（或在对话里说选中）。同时读 `data/reviews/<方案 id>.json` 的批注
- **用户直接给**：一句表达加一点背景（谁、什么情绪）也可以开始；先补一张最小表达卡：表达、句式、圈层、情绪范围、主载体，并说明是补的
- **已有形象图要改**：不是这一步。说明属于第三步的诊断模块，建议用 chaowan-ip-studio

## 流程

**第 0 步：读历史。** 读这个方案在 `data/forms/` 下已有的形，以及每个形在 `data/reviews/` 的状态和批注。被淘汰的方向不再出；批注直接变成约束，并在交付时说明怎么照着改的。

**第 1 步：列约束。** 从表达卡里抄出不能动的东西：表达、句式、表达的情绪、脸上的情绪（可以 / 不可以）、它的状态、原点转译和结构种子、圈层、主载体、用户锁定的点。脸上的情绪决定第④⑤轴能走多远（见 `axes.md`）。旧表达卡只有一个"情绪范围"和"它在做什么"时，先按 lab v2.1 补成两栏情绪和"状态"，说明是补的；"它在做什么"是动作时，翻译成状态，不照着画动作。

**第 2 步：排轴矩阵（第一轮）。** 按 `axes.md` 给 6 个形各定五条轴和头型的取值，先画成一张表，检查拉开规则和潮玩范式的配额：至少 5 个大头小身或头身一体、至少 5 个主记忆点在头上、最多 1 个探索位、五官至少 3 种眼型。出图方式（白模或线稿）全轮统一。表过了再往下写。

**第 3 步：写规格。** 每个形按 `form-and-prompts.md` 写最小造型规格和"识别组合"：3 到 4 个具体的几何关系（比例、位置、尺度反差），让人一眼认出它是谁。比例用倍数写（头高约占全高的 55%、眼睛在头高下三分之一处），研究库的测试显示这比"大头""小眼"稳。情绪只在静态里表达：眼皮、视线、嘴、重心，以及一个能定格的标志性姿态和手脚的尺度（张开双臂、单手高举、放大的手、大人的鞋）。一轮里至少 2 个不是立正。

**第 4 步：检查。** 按 `checks.md` 做撞车检查、外壳与内核检查、禁止项和潮玩感自检；五项测试写风险和验证方式，标"待出图验证"。

**第 5 步：写提示词。** 按 `form-and-prompts.md` 的模板，中英文同义：默认白模，正面站立全身，右下角同姿态小黑剪影；用户选线稿时换成线稿模板。按"比例 → 头型 → 五官 → 身体与站姿 → 识别组合与反常点 → 画面要求 → 负面词"写几何，不写故事和动作。负面词整段照抄，再加这个形最容易画错的两三项。不写任何现有 IP、品牌或艺术家的名字。

**第 6 步：输出与写入。** 用下面的形卡格式输出；有仓库时写入（见"写入仓库"）。最后两三句话说明 6 个形之间的取舍，不排名次。

## 第二轮：裂变

用户把某个形标保留（或说"就这个方向"）后：
- 在它基础上出 **4 个**变体：原型和整体轮廓不动，只在记忆点的细节、五官、反常点里变化，每个变体写清和母版差在哪
- **第二轮起用参考图**：把母版的图作为参考图，提示词第一句写"保持参考图的比例、头型和体块不变，只改下面几处"。研究库的复现测试里，纯文字大多四轮还没过，带参考图的版本通过率高得多
- 用户标"待优化"并写了批注的形，按批注出一个修订版，只改批注提到的地方
- 第二轮也可以再裂变，直到用户锁定

## 锁定

用户说"锁定""定了"，或在第二轮里把某个形标保留并说明要往下走时：
1. 读 `handoff.md`，生成 `ip-archives/IP档案_<名字>_v1.md`。不变量里写进这个形的轮廓、头身关系、记忆点、五官配置和核心情绪，具体到可以检查
2. 这个形的白模或线稿是第三步上色、出三视图的参考图，档案里写明路径
3. 在形的数据里把 `locked` 设为 `true`，提示进入第三步 chaowan-ip-studio

## 形卡格式

```
### 形 <轮次字母><序号>：<一句话概括这个形>

| 轴 | 取值 |
|---|---|
| ① 原型 | |
| ② 整体轮廓 | |
| ③ 记忆点 | 位置 · 是什么 |
| ④ 五官 | |
| ⑤ 情绪表达 | 静态：眼皮、视线、嘴、重心 |
| 姿态与手脚尺度 | 立正、张臂、举手……；手脚放大或缩小 |
| 头型 | |
| 反常点 | 0 到 2 处，最好是尺度或属性反差；没有写"无" |

**怎么长出表达**：这个形为什么能说出那句话（一两句）
**识别组合**：3 到 4 个具体的几何关系
**造型规格**：比例 / 头型 / 五官几何 / 身体与站姿 / 结构连接（按 form-and-prompts.md）
**裁切检验**：只剩头像时靠什么认出它（记忆点在头上时写"记忆点在头部"）
**撞车检查**：最接近的现有 IP 和差别
**潮玩感自检**：五问各一句（按 checks.md）
**五项测试**：待出图验证，各写一个最可能的风险
**提示词**：白模中文一版、英文一版（用户要线稿时换线稿模板）
```

## 写入仓库

仓库 `ashlandkrug878-wq/ip`，规则见仓库根目录 `AGENTS.md`：
- 每个形写一个文件 `data/forms/<方案 id>-<轮次字母><序号>.json`，例如 `data/forms/2026w42b-1-A3.json`。字段见 `references/form-and-prompts.md` 末尾
- 运行 `python scripts/build_index.py` 和 `python scripts/build_queue.py`（会给每个形加一个出图任务；任务类型和文件名沿用 `lineart`、`lineart-01.webp`，白模也存这个路径，网站不用改），一起提交推送
- 用户在选品板网站「找形」一栏挑选和上传图；不要改 `data/reviews/` 里用户写的东西
