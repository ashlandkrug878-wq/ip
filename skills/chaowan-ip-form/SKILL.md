# 潮玩 IP 找形 v1.0 · 工作流第二步

**这一步只做一件事：给一个表达找到对的形。** 输入是表达，输出是一组可以并排比较的黑白线稿方向；用户挑中一个、微调、锁定，生成 IP 档案交给第三步。

为什么单独一步：形还没找对就上颜色和材质，画面会被质感撑起来，看不出造型本身好不好；一个表达只出一张图，AI 给的往往是最平均的解。所以这里只看形，而且一次看很多个。

原则：
1. **表达先于特点。** 每个形都要说清它怎么把表达"长"出来；只是好看、和表达没关系的形不要
2. **只看形，不看质感。** 线稿阶段不写颜色、材质、灯光和渲染精度
3. **拉开再收拢。** 第一轮在大方向上拉开差异，第二轮只在选中的方向里微调
4. **AI 生成，人挑选。** 不打分、不排名；AI 只指出结构和辨识上的问题，保留还是淘汰由用户决定
5. **没看到图不下结论。** 只有文字时五项测试都写"待出图验证"

## 输入

- **标准输入**：仓库 `data/ips/<方案 id>.json` 里的表达卡，用户在选品板上标了保留（或在对话里说选中）。同时读 `data/reviews/<方案 id>.json` 的批注
- **用户直接给**：一句表达加一点背景（谁、什么情绪）也可以开始；先补一张最小表达卡：表达、句式、圈层、情绪范围、主载体，并说明是补的
- **已有形象图要改**：不是这一步。说明属于第三步的诊断模块，建议用 chaowan-ip-studio

## 流程

**第 0 步：读历史。** 读这个方案在 `data/forms/` 下已有的形，以及每个形在 `data/reviews/` 的状态和批注。被淘汰的方向不再出；批注直接变成约束，并在交付时说明怎么照着改的。

**第 1 步：列约束。** 从表达卡里抄出不能动的东西：表达、句式、情绪范围、圈层、主载体、用户锁定的点。情绪范围决定第④⑤轴能走多远（见 `axes.md`）。

**第 2 步：排轴矩阵（第一轮）。** 按 `axes.md` 给 6 个形各定五条轴的取值，先画成一张表，检查拉开规则：任意两个至少两条轴不同，原型和整体轮廓不能同时相同。线条语言全轮统一。表过了再往下写。

**第 3 步：写规格。** 每个形按 `form-and-prompts.md` 的最小造型规格写清轮廓、体块、头脸几何、记忆点位置、情绪怎么从五官和姿态露出来、结构连接。记忆点不在头上时，写一句裁切检验：只剩头像时靠什么认出它。

**第 4 步：检查。** 按 `checks.md` 做撞车检查、外壳与内核检查、禁止项；五项测试写风险和验证方式，标"待出图验证"。

**第 5 步：写线稿提示词。** 按 `form-and-prompts.md` 的线稿模板，中英文同义：白底黑白线稿，主体正面全身，右下角同姿态小黑剪影。不写颜色、材质、灯光，不写任何现有 IP、品牌或艺术家的名字。

**第 6 步：输出与写入。** 用下面的形卡格式输出；有仓库时写入（见"写入仓库"）。最后两三句话说明 6 个形之间的取舍，不排名次。

## 第二轮：裂变

用户把某个形标保留（或说"就这个方向"）后：
- 在它基础上出 **4 个**变体：原型和整体轮廓不动，只在记忆点的细节、五官、反常点里变化，每个变体写清和母版差在哪
- 用户标"待优化"并写了批注的形，按批注出一个修订版，只改批注提到的地方
- 第二轮也可以再裂变，直到用户锁定

## 锁定

用户说"锁定""定了"，或在第二轮里把某个形标保留并说明要往下走时：
1. 读 `handoff.md`，生成 `ip-archives/IP档案_<名字>_v1.md`。不变量里写进这个形的轮廓、头身关系、记忆点、五官配置和核心情绪，具体到可以检查
2. 这个形的线稿是第三步上色、出三视图的参考图，档案里写明路径
3. 在形的数据里把 `locked` 设为 `true`，提示进入第三步 chaowan-ip-studio

## 形卡格式

```
### 形 <轮次字母><序号>：<一句话概括这个形>

| 轴 | 取值 |
|---|---|
| ① 原型 | |
| ② 整体轮廓 | |
| ③ 记忆点 | 位置 · 是什么 |
| ④ 五官 | |
| ⑤ 情绪表达 | |
| 反常点 | 0 到 2 处，没有写"无" |

**怎么长出表达**：这个形为什么能说出那句话（一两句）
**造型规格**：轮廓 / 体块 / 头脸几何 / 结构连接（按 form-and-prompts.md）
**裁切检验**：只剩头像时靠什么认出它（记忆点在头上时写"记忆点在头部"）
**撞车检查**：最接近的现有 IP 和差别
**五项测试**：待出图验证，各写一个最可能的风险
**线稿提示词**：中文一版、英文一版
```

## 写入仓库

仓库 `ashlandkrug878-wq/ip`，规则见仓库根目录 `AGENTS.md`：
- 每个形写一个文件 `data/forms/<方案 id>-<轮次字母><序号>.json`，例如 `data/forms/2026w42b-1-A3.json`。字段见 `references/form-and-prompts.md` 末尾
- 运行 `python scripts/build_index.py` 和 `python scripts/build_queue.py`（会给每个形加一个线稿出图任务），一起提交推送
- 用户在选品板网站「找形」一栏挑选和上传线稿；不要改 `data/reviews/` 里用户写的东西
