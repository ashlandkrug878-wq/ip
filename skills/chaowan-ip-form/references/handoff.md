# 交接：IP 档案

用户锁定一个形之后，生成这份 IP 档案。它是找形交给第三步（chaowan-ip-studio）的唯一文件，第三步每个模块都以它为依据，并在完成后更新它。

生成规则：
- 内容来自表达卡和锁定的形，不在交接时新增设定
- "不变量"写到可以检查的程度，例如"无腿横宽扁豆轮廓，双臂从左右上侧肩根长出，约为身体高度两倍"，而不是"手很长"
- 找形没有定的内容（颜色、材质、动作库、口头禅、故事、工艺）写"待第三步补充"
- 存到仓库 `ip-archives/IP档案_<名字>_v1.md`，同时在形的数据里把 `locked` 设为 `true`

# IP 档案：<名字>（<英文名>）
