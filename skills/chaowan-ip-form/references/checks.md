## 1. 外壳与内核

- **外壳**：样子。可以和别人相似，只要及格、好看
- **内核**：表达、性格、情绪、背景，决定它是"谁"
- **"有别人的影子"**：外壳主要由公共元素构成（雀斑、腮红、大眼睛、双马尾、嘟嘴、眼镜等），并且内核空缺或和别人相同
- 只是外形有点像、内核独特，属于正常借鉴，就像长得像某位明星的人，有自己的性格，大家记住的就是他本人
- 但内核独特不能抵消外形过近：整体轮廓、五官组合和比例都和某个现有 IP 很像时，仍然要改

找形阶段的内核来自表达卡。每个形都要写"怎么长出表达"，写不出来的，说明外壳和内核脱节，换掉。

## 2. 撞车检查

先读仓库 `data/studies/` 里的对标卡（第 0 步 chaowan-ip-study 的研究结果）：`collide_combo` 是要避开的识别组合，`form` 一节能看出哪些原型、轮廓、记忆点位置已经拥挤。对标卡有来源，和 `benchmarks.md` 冲突时以对标卡为准，并在交付时提出来。再用 `benchmarks.md` 的识别组合对照：
- 比整体组合，不比单个元素：无嘴、尖牙、大眼这些通用元素不归任何 IP 独占
- 原型、整体轮廓、五官组合三样里有两样和某个 IP 很像，就算撞车，写清改哪里
- 写出最接近的 IP 和差别；找不到接近的写"未发现明显接近"

## 3. 记忆点与反常点

- 记忆点一个，最多两个，其余都是配角
- 主记忆点默认在头上（头型、头顶整体形状、五官配置），身体只做次要记忆点；探索位可以例外。放在头上也不是在头顶加装饰，而是头型和脸本身就有辨识度
- 记忆点不在头上时写裁切检验；头像场景认不出，就给头部补一个辅助特征
- 反常点每个形 0 到 2 处，不强制。反常要读成"装饰"而不是"异常"：单个、轮廓清楚、从身体往外长的像装饰；大面积、重复、贴着皮肤的像病变

## 4. 五项测试

分证据阶段记录：
- **只有文字**：五项都写"待出图验证"，各写一个最可能的风险
- **有实际图**：写依据，给"通过 / 存疑 / 不通过"；没做的变体写"未验证"

1. **记忆点复述**：看图后能一句话说出它的轮廓和情绪吗？（这是观察判断，不是真人记忆实验）
2. **剪影**：看右下角黑剪影，头、身体、突出物还分得开吗？
3. **简化**：删掉次要线条，三五笔还能画出来吗？
4. **缩小**：缩到手机头像大小还认得出吗？
5. **换皮**：换衣服、颜色、材质，还是它吗？去掉可拆道具后呢？（拟物和功能角色保留主体结构）

技术检查不等于用户的保留或淘汰。

## 5. 禁止项与工艺提醒

禁止：
- 大面积重复纹理放在脸上（鱼鳞、密集斑点、孔洞），容易引起密集恐惧或病变联想
- 照搬某个 IP 的具体识别组合
- 提示词里写现有 IP、品牌或艺术家的名字
- 用真实商标做造型元素

工艺提醒（只提示，详细的在第三步）：
- 毛绒做不好细框眼镜、发丝、精细表情 → 改搪胶脸或刺绣
- 结构复杂（多零件、多模具）首发成本高。成本排序：造型结构 > 零件 > 颜色
- 细长的突出结构要考虑能不能立住、会不会断

## 6. 潮玩感自检

每个形写提示词前过一遍，写进形卡。任何一问答"否"，回去改规格（第 6 问看整轮）：
1. **站得住吗？** 正面站立、双脚着地、重心在两脚之间，放在桌上不倒
2. **换成搪胶或毛绒还成立吗？** 没有细到做不出来的线、没有悬空的薄片、没有靠渲染撑着的细节
3. **去掉动作还认得出吗？** 识别靠头型和脸，不靠姿势和场景
4. **像不像儿童绘本或吉祥物？** 圆眼张嘴笑、腮红、细长手脚、速度线，有一样就要警惕
5. **缩到盲盒大小还剩什么？** 剩下的应该正好是识别组合
6. **身体在说话吗？** 一轮里至少 2 个不是立正；脸收着的形，劲儿有没有交给姿态或手脚的尺度

## 7. 交付前自查

- 矩阵过了拉开规则
- 每个形写出了"怎么长出表达"
- 规格写到能画：轮廓、体块、头脸几何、结构连接
- 脸上的情绪在表达卡的范围里，没有张嘴大笑（除非表达卡允许）
- 潮玩配额过了：至少 5 个默认原型和轮廓、至少 5 个主记忆点在头上、五官至少 3 种眼型
- 每个形写了识别组合，过了潮玩感自检
- 提示词写的是几何不是故事，带了固定负面词；没有颜色、材质纹理和别人的名字
- 没看到图的测试都写着"待出图验证"
