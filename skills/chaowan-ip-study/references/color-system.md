# 色彩系统、色板与材料色差

完整调研必读。本节是研究已有色彩，不是替对象设计新色系。

## 四种身份

- official_standard：官方手册给出的标准色、编号或数值。附手册版本、许可范围和来源。
- recurring_identity：跨作品重复、可能参与识别的颜色关系；研究归纳，不能升格为官方强制不变量。
- series_palette：某SKU／主题的主辅配色，不能推广至全IP。
- editorial_environment：书籍、包装、海报、场景、灯光背景的颜色；与角色本体分表。

## 每套色板必须回答

主色：大面积主体色；识别／签名色候选：小面积或重复关系中承担识别的颜色；辅助色：服装道具；中性色：面部、纸张、留白等；线稿／五官色；点缀色。可一色多职，但明确作用，不强行凑6色。

逐色记录：palette_id、color_id、色名、role、scope、hex_preview、value_basis（官方／图像取样／视觉估计）、surface_or_region、image_ids、evidence_ids、sample_method、sample_coordinates_or_mask、area_description、area_basis、material_context、variation_boundary、uncertainty。

色值未经官方确认均为屏幕近似预览；不得编造Pantone、Coloro或供应商色号。图像取样记录实际尺寸、原图与取样点／区域、RGB转换方式、取均值／中位数方法及光照局限。不能把网页背景计入主体面积。没有主体分割就只写面积等级，不给假装实测的70/20/10。

## 跨样本比较

至少对照基础／首发、2D插画、实物及明显异色系列，分别回答：什么颜色稳定、变色时靠什么仍被认出、哪个颜色是主题而不是身份、强反差是否破坏五官层次。

主色可以变而签名色仍保留是候选机制，不假设所有IP都如此；先找反例。借鉴的是色彩关系与识别机制，不能搬用具体角色的轮廓＋五官＋配色组合。

## 检查与工艺

分别记录灰度、头像缩小、浅深杂背景、不同材料上的可读性。实际做过写方法和样本，未做写未验证。截图缩图不是实物5cm验证。

同色在纺织、PVC、搪胶、透明件、移印、刺绣会受毛长、反射、底色、染色与印刷影响；只对有证据的SKU描述，不能声称某材料一律偏暗或偏亮。生产需实物色卡及打样，屏幕HEX不能直接作为验收标准。

## 提示词交接

找形线稿文本不写颜色、材质或摄影。上色文本锁定参考造型，只写色块分区和保留的识别色关系。产品文本再写部位材质与工艺；摄影最后单独一层。身份参考与画风参考必须分开，防止把背景和光照画成角色身体。
