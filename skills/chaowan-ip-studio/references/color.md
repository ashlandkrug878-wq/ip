# 模块 2：配色与选材

**先读 `pools.md`。** 配色从用户的色系池和单色收藏里挑，选材从材质池里挑；池里没有合适的，才提议新的，并建议用户存进池里。下面是挑选和检查的标准。

## 角色色板的结构

| 角色 | 作用 | 规则 |
|---|---|---|
| 主色 | 身体大面积的颜色 | 可以随系列变，但第一款要稳 |
| 签名色 | 小面积、高识别，通常在记忆点上 | **不变量**，所有系列都保留 |
| 辅色 | 服装、配件 | 跟随系列主题 |
| 线稿色 | 轮廓线、五官 | 一般不用纯黑，用深一档的主色更柔和 |

规律：三丽鸥是白底加一个签名色；史迪奇、奶龙、草莓熊是单色识别。颜色是变量，签名色是常量。

每个颜色给色名和近似色值（例如"番茄红 #E4573D"），并提醒：屏幕色值只是参考，打样以实物色卡为准。

## 系列配色怎么变

- **季节**：春夏提亮降饱和，秋冬加深加暖
- **节日**：只在辅色和配件上加节日色，签名色不动
- **前瞻色引入**：把年度色、季度关键色用在限定款或配件上，而不是改主体。年度色人人会用，当主色会撞车
- **反差款**：隐藏款可以做一次大反差（例如"冷静的蓝色火"），但记忆点的形状要保留

## 检查

1. **灰度测试**：转成黑白，记忆点和五官还分得清吗？分不清说明靠色相区分，明度差不够
2. **缩小测试**：缩到 5 厘米挂件或手机头像，签名色还看得见吗？
3. **背景测试**：放在浅色、深色、杂乱的照片背景上，还跳得出来吗？用户会把它放进各种照片里
4. **同类对比**：和对标库里同类 IP 的主色比，有没有撞色
5. **材质色差**：同一个颜色在毛绒、搪胶、PVC 上效果差很多；毛绒会偏暗偏灰，搪胶会偏亮，透明件会偏淡。按首发品类提醒

## 输出

- 主色板一份（色名、色值、用在哪）
- 系列配色二到三套（主题、色板、哪些不变）
- 检查结论
- 改色后的出图提示词
