# 模块 5：表情包与动作

主载体是短视频或表情包的 IP，这个模块最重要。表情包和短视频需要的不是精致的造型，而是"能一直演"：动作和表情丰富、线条简单到能大量绘制。

## 经典动作库

先做动作，再做表情包。每个动作写四项：
- **触发情绪**：什么情况下会做这个动作
- **动作过程**：起始姿态 → 过程 → 结束姿态，两到四拍
- **和记忆点的互动**：最好的动作都在"使用"记忆点（例如头顶的火气团被捏瘪、头顶的灯变颜色）
- **圈层用法**：用户会在什么聊天场景里发它

动作设计原则：
- 从核心性格里来，不和不变量冲突
- 夸张，轮廓在剪影里也能看懂
- 能循环（表情包和短视频都需要）
- 一个 IP 先做三到五个经典动作，让用户记住，再慢慢扩

## 表情包清单

一套建议 16 或 24 个，分四类：
- **日常回应**：好的、收到、在吗、晚安、谢谢
- **情绪**：开心、生气、崩溃、无语、委屈、得意
- **圈层黑话**：用圈层画像里的黑话和梗写文案，这部分最能传播
- **节日和节点**：生日、新年、考试周、年终等

每个表情写：编号、动作或表情、文案、使用场景。文案要短，四到六个字最好。

## 短视频动作分镜

适合 MCN 和短视频载体：
- 时长短，开头一两秒就要出现记忆点
- 结构：钩子（异常或冲突）→ 经典动作 → 口头禅或文案 → 循环点
- 每条分镜写：镜头、动作、时长、文字或配音、音效

## 出图提示词

每个表情或动作的提示词都复用角色设定图的固定描述段（见 `illustration.md`），只改动作和表情；背景统一，便于做成一套。

## 输出

- 经典动作库（三到五个）
- 表情包清单
- 一到三条短视频分镜
- 对应的出图提示词
