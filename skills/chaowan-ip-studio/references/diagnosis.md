# 模块 1：诊断改造

形象出来以后，最常见的问题是"好看，但有别人的影子""没有特色"。这个模块负责说清楚问题在哪、怎么改。

## 步骤

1. **对照档案**：有档案时，先检查出图结果有没有守住不变量（记忆点是否被画丢、签名色是否跑偏、头身比是否变了）。出图工具经常把记忆点画弱，这是第一个要查的
2. **逐层拆解**：原型、头身比、体型、表情、姿势、服装、配色、材质
3. **头脸与体块**：按 `head.md` 记录轮廓、眼型、五官位置、留白和大中小体块。标签只做描述；普通元素的特殊比例组合也能独特，反常附件不保证质量
4. **影子判断**（见下）
5. **五项测试**：记忆点复述、剪影、简化、缩小、换皮，记录图和版本、证据及结论。只有文字均写“待出图验证”；未制作或查看的变体标“未验证”。观察判断不伪称真人闭眼实验；屏幕缩图不等于实物工艺测试。去可拆道具检查保留拟物主体和关键功能结构
6. **找表达种子**：形象里已有、但没被用起来的东西（一句文案、一个道具、一个姿势、一个名字），优先从这里长出表达或专属元素，而不是另起炉灶
7. **给出改法**：保留什么、删掉什么、调整哪些几何或结构关系，不强制增加附件；改完后该重跑哪几项测试
8. **改版提示词**：中英文各一版，记忆点写在最前面并加强

## 分清问题来源

| 问题 | 检查证据 | 优先处理 |
|---|---|---|
| 创意与表达 | 矛盾、态度与动作是否有关系 | 补内核，不用附加符号代替 |
| 角色造型 | 头脸几何、留白、轮廓、体块是否具体 | 先改比例与形状，不靠材质救 |
| 通用萌物加道具 | 移除可拆附件后是否只剩默认宝宝或动物 | 设计角色本体；拟物角色不拆主体 |
| 材质转译 | 绒长、颗粒、透明与脸部工艺是否合适 | 明确分区，保住面部可读性 |
| 执行偏差 | 实际图是否违背提示词或不变量 | 只修失真的地方，不重写身份 |
| 结构问题 | 肢体起点、接触点、重心、挂点是否连续 | 修连接与遮挡，不用背景遮盖 |
| 相似性 | 整体轮廓、五官组合、比例与配色是否过近 | 对照实际参考指出具体组合，不以公共元素定罪 |

表达独特不能自动消除外形过近的问题；普通元素也不等于抄袭。按问题所在层修，不强制先补内核再加专属元素。
毛绒、可爱、极简或繁复均可成立，不把“潮玩”限定成一种脸。渲染精细度与设计完成度分开评价。
改版提示词按“轮廓与体块 → 头脸几何 → 表情姿态 → 色块 → 材质分区和五官工艺 → 中性展示 → 针对性避免项”写，中英文同义。不用“更高级、更潮玩”代替几何指令。
用户只要一张成图时在该图内落实约束，不额外强制四阶段出图；需要验证时推荐先黑白或低细节造型，定脸后配色和渲染。修改触及已确认不变量时先说明具体冲突，未获授权不改。

## 多个版本时

用户给了同一个形象的插画版、3D 版、实物版时：
- 比较哪个版本保留了最多个性（手绘笔触、不完美的线条、材质感）
- AI 渲染和 3D 化常常会把个性磨平，变成标准的光滑公仔；提醒在转实物时把个性保留下来，例如哑光、微绒、手绘线条印花

## 品牌元素提醒

形象里用了真实品牌的商标、经典图案或标志性设计时，指出商用需要授权，并给出不依赖品牌的替代方案。

## 说话方式

坦诚、具体：点名哪个元素是公共的、像谁；同时说清楚好的部分。不要只说"挺好的"，也不要只挑毛病。
