# 头脸拆解：17 项

记忆点位置不限，头脸是常见入口之一，整体轮廓、比例和姿态也可承担识别。标签是描述词汇，不是元素所有权或质量判定表。

- **[公共]** 很多人使用，单个元素通常不足以识别角色；特殊比例与组合仍能形成 ID
- **[专属]** 本库中某种具体组合有代表性；不代表单个 IP 独占无嘴、尖牙、大眼等通用元素。检查整体组合相似性，避免复刻具体角色
- **[反常]** 相对所选原型违反预期；不强制出现，全身合计 0 到 2 处

## 头型与头顶
1. **头型**：圆 [公共]、椭圆 [公共]、团子 [公共]、方 [反常]、拟物头 [专属]（YOYO 南瓜头）、尖耳轮廓 [专属]（LABUBU）
2. **发型**：齐刘海、中分、双马尾、丸子头、短卷发 [均为公共]；云朵发 [专属]（DIMOO）；光头 [反常]
3. **发色**：自然棕黑、金色、随系列变 [公共]；奇幻色 [反常]
4. **耳朵**：无、人耳、动物耳 [公共]；超长耳 [专属]（大耳狗）
5. **头饰头套**：蝴蝶结、皇冠 [公共]；头巾 [专属]（美乐蒂）；兜帽 [专属]（星星人）；动物头套 [专属]（HACIPUPU）
6. **长出来的东西**：角、花 [反常]；草 [反常·已占]（长草颜团子）；蘑菇帽 [反常·已占]（孢绒绒）

## 眉眼
7. **眉毛**：无、小短眉、八字眉（显委屈）、挑眉（显得意）[公共]；粗眉 [专属]
8. **眼型**：大圆眼、豆豆眼、半垂眼、眯成线 [公共]；全黑无瞳 [专属]
9. **眼距**：正常 [公共]；宽眼距、窄眼距 [反常]
10. **眼神**：正视、斜视、放空、向上看 [公共]
11. **眼部附加**：睫毛、眼影 [公共]；眼泪 [专属]（CRYBABY）；黑眼圈 [专属]（欧潘迪）

## 鼻嘴与脸
12. **鼻子**：无、小圆点、动物鼻 [公共]；红鼻头 [专属]（孢绒绒）
13. **嘴**：一条线、猫嘴 [公共]；无嘴 [专属]（Kitty、YOYO）；嘟嘴 [专属]（MOLLY，已被大量模仿，接近公共）；尖牙 [专属]（LABUBU）；大嘴 [专属]（奶龙）；歪嘴 [专属]（孢绒绒）
14. **脸颊**：腮红、雀斑、无 [公共]
15. **肤色**：自然、白瓷 [公共]；奇幻色 [反常]（汉顿、史迪奇）
16. **小标记与配饰**：眼镜、发夹、耳环、胡须、痣 [公共]；创可贴 [专属]；伤疤、彩绘 [反常]
17. **表情可变性**：固定表情 [公共]；可换脸 [反常]

## 头脸设计规则

- **先画关系，再加附件。** 写头部横纵关系、脸颊与下巴走向、五官高度和间距、眼睛外轮廓与眼皮遮挡、嘴的形状及偏移。相对几何描述足够，不强求虚假的精确数值。
- **选择视觉重心。** 可集中在眼、嘴或整体脸型，其余支持它；复杂风格也要有层次，不必都删成豆豆眼。
- **组合可以独特。** 常见元素通过比例与位置也能形成身份；标签数量和头顶装饰不构成通过凭证。
- **眼睛要可执行。** “半垂眼”还须说明眼型、眼皮轮廓、视线和左右关系；“宽眼距”须联系头宽或脸部留白。
- **与载体匹配。** 图形眼可用刺绣或移印，雕塑眼皮用体块；不默认真实眼球、皮肤或玻璃珠高光。
- **区分参考角色。** 用户角色图约束身份，风格图只借形式语言。Luna 可参照设计完成度，不能把她的眼镜、双辫或脸型套给所有角色。
