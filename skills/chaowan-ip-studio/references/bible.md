# IP 档案：读、写、更新

IP 档案是两步之间的交接文件，也是第二步所有模块的共同依据。第一步 chaowan-ip-lab 生成 v1；第二步每个模块完成后更新它。

## 读档案

进入任何模块前，先从档案里取出：
- 不变量（这一模块不能动的东西）
- 圈层的黑话符号（文案、彩蛋、表情包都要用）
- 主载体（决定模块的优先级和做法）
- 已有的内容（避免和已有设定冲突）

## 没有档案时补一份

用户带着自己的形象直接进来时，在模块 1 诊断的最后补档案：
- 不变量：从诊断结论里挑出这个形象最该守住的东西
- 内核：如果用户说不出洞察和圈层，按诊断推测一版并标"推测"，提醒用户确认；也可以建议用户回第一步把内核补扎实
- 其他字段能填的填，填不了的写"待补充"

## 更新档案

- 每个模块完成后更新，版本号加一（v1 → v2）
- 在"变更记录"里写一条：日期 · 模块 · 改了什么 · 为什么
- 不变量只有在用户明确同意、并且判断为版本升级时才能改；判断为裂变时，另起一份新档案

## 模板

```markdown
# IP 档案：<名字>（<英文名>）
版本：vN · 来源 · 日期

## 不变量（任何模块都不能改）
- 表达：
- 记忆点：
- 轮廓与头身比：
- 签名色：
- 核心性格：

## 内核
- 洞察：场景 / 行为 / 状态 / 矛盾 / 没说出口的话（附来源）
- 圈层：是谁 / 在哪 / 已经在买什么 / 黑话符号 / 怎么晒 / 破圈路径
- 时机站位：
- 用到的前瞻信号：

## 外形
- 原型 · 物种 · 体型 · 招牌姿势 · 命名
- 头部元素（逐项，带公共、专属、反常标签）
- 主色 · 细节密度 · 手感
- 基础形象出图提示词
- 外形线稿（定稿版本说明）
- 角色设定图提示词（模块 3）

## 色板与材质（模块 2）
- 选用的色系：来自色系池的哪一套（名字）
- 主色 · 签名色 · 辅色 · 线稿色（色名 + 近似色值）
- 选用的材质：来自材质池的哪几种，用在哪个部位
- 系列配色

## 内容
- 主载体 · 次载体
- 经典动作库（模块 4）
- 表情包清单（模块 4）
- 口头禅与常用文案（模块 5）
- 世界观与关系（模块 5）
- 故事线（模块 5）

## 变量（可以随系列变）
- 服装 · 配色 · 场景 · 材质 · 联名

## 系列（模块 6）
- 已出 / 规划中的系列 · 节点日历 · 联名方向

## 产品（模块 7）
- 首发品类与工艺 · 价格带 · 稀缺机制 · 打样状态 · 验证数据

## 变更记录
- 日期 · 模块 · 改了什么 · 为什么
```
