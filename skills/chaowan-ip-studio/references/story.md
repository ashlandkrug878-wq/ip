# 模块 6：故事走向

绘本、漫画、表情包出身的 IP 自带内容，生命力更长；纯造型出身的需要后补内容。这个模块负责补上。

## 世界观最小单元

不需要宏大的世界观，先回答五个问题：
1. 它住在哪里？
2. 它每天在做什么？
3. 它最想要什么？
4. 它最怕什么？
5. 它和用户是什么关系？（朋友、搭子、替身、宠物、守护者）

答案要和洞察对得上：它的"最想要"和"最怕"，最好就是圈层身上的那个矛盾。

## 关系设计

- **单人**：故事靠它和用户、和环境的互动
- **对手搭档**：两个性格相反的角色（美乐蒂和酷洛米式），一个角色讲一种情绪，一组能讲故事，也能承接两类人群
- **情侣**：适合送礼和纪念日
- **群像**：适合漫画和长期连载（Chiikawa 式）

新角色要先过一遍判断：它是这个 IP 的配角，还是应该独立成新 IP（见 `series.md` 的裂变判断）。

## 口头禅

- 两到三句，从表达和"没说出口的话"里来
- 短，可以单独做成表情包或吊牌文案
- 用圈层的语言

## 故事线

- 按季度规划，每季一个主题，和节点（节日、生肖、季节、考试周、年终）对齐
- 每个主题写：起因、冲突、经典动作出现在哪、结尾的情绪
- 故事线可以直接变成系列（见 `series.md`），一个故事对应一个系列最好

## 短视频脚本模板

```
标题：
时长：
钩子（开头 1 到 2 秒）：
冲突：
经典动作：
口头禅或结尾文案：
循环点或互动引导：
```

## 输出

- 世界观最小单元（五问五答）
- 关系图
- 口头禅
- 一个季度的故事线
- 两到三条短视频脚本
