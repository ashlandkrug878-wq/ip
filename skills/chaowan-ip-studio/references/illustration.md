# 模块 4：插画与海报（三视图见模块 3 和 render.md）

## 第一步永远是角色设定图

出插画和海报之前，先出一张角色设定图，否则每张图里的角色都会长得不一样：
- 正面、侧面、背面三视图
- 四到六个核心表情
- 记忆点的特写
- 色板标注

设定图的提示词要写成一段**固定描述**（外形、记忆点、比例、配色、材质），之后所有插画和海报的提示词都原样复用这段，只改场景和动作。出图工具支持参考图时，把设定图作为参考图一起使用。

## 画风选择

画风跟着主载体和圈层走：
- 实物潮玩的主视觉：3D 软胶渲染、棚拍光，接近产品实物
- 海报和社交平台：可以更插画化，蜡笔、彩铅、水彩、扁平都可以，选和表达气质一致的
- 手作感能对抗 AI 图的平滑，提示词里写"可见手绘笔触、轻微不完美的线条、纸张纹理"
- 一个 IP 的画风最多两到三种，并且固定下来

## 图的类型

| 类型 | 用途 | 构图要点 |
|---|---|---|
| 主视觉 | 品牌首图、发布 | 角色居中，记忆点在视觉中心，留出放标题的空间 |
| 系列海报 | 每个新系列 | 同一套版式，换主题和场景 |
| 场景插画 | 社交平台日常 | 角色出现在圈层熟悉的场景里（工位、宿舍、床头） |
| 节日海报 | 节点营销 | 节日元素放在辅色和道具上，角色本身不改 |
| 产品示意图 | 测款发布 | 接近实物材质，带包装或挂件形态，用来测点赞和预约 |

## 构图规则

- 记忆点要在第一眼的位置，不能被道具或文字挡住
- 一张图只讲一件事
- 文字和角色不抢：留白给文案，文案用圈层的黑话
- 系列海报保持同一个版式，形成识别

## 输出

- 角色设定图提示词（固定描述段）
- 画风说明
- 每张图：用途、构图说明、场景、文案建议、中英文出图提示词
