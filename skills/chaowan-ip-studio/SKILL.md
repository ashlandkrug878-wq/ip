# 潮玩 IP 工作室 v1.2 · 工作流第二步

**这一步的起点是一个已经选定的基础形象。** 目标是让它从"一张图"变成一个有动作、有性格、有故事、有产品线的 IP。七个模块可以单独调用，不必按顺序全部走完。

## 输入

- **标准输入**：第一步交来的 IP 档案（`IP档案_<名字>_vN.md`）+ 外形线稿或基础形象图
- **素材池**：用户在选品板上存的色系池、单色收藏、材质池，是配色和选材的来源（见 `references/pools.md`）
- **没有档案时**（用户直接带着自己的形象来）：先走模块 1 诊断改造，在诊断的最后按 `references/bible.md` 补一份 IP 档案，再进入其他模块
- 用户发来的是一个原点、还没有形象时，说明这属于第一步，建议使用 chaowan-ip-lab

## 共同原则

1. **不变量不能动。** 表达、记忆点、轮廓与头身比、签名色、核心性格写在 IP 档案的"不变量"里，任何模块都不能改。用户要求的改动会碰到不变量时，先指出来，并按 `references/series.md` 判断这是版本升级还是应该裂变成新 IP
2. **每个模块交付后更新档案。** 新增的色板、动作、口头禅、关系、故事、系列、工艺都写回 IP 档案，版本号加一，并记一条变更记录。档案是唯一真相
3. **按载体排优先级。** 主载体是短视频或表情包的，优先做模块 4 和 5；主载体是实物潮玩的，优先做模块 2 和 7；主载体是海报的，优先做模块 3
4. **人负责校准。** 每个模块交付后，问用户一个问题：这一版通过了吗，下一步进入哪个模块。不要一次把七个模块全做完
5. **先线稿，后配色，再选材。** 外形线稿定下来才进入配色，配色从素材池的色系里挑；配色定了再从材质池选材
6. **不写别人的名字。** 所有出图提示词里不写现有 IP、品牌或艺术家的名字，也不写"像某某"

## 判断进入哪个模块

## 每个模块的交付物

**模块 1 诊断改造**：先区分创意、造型、材质和渲染问题，提供轮廓、头脸几何、体块、去可拆道具后的识别和结构连接的证据；五项测试区分实际验证与未验证；给保留删改清单和中英文改版提示词，没有档案时补档案。不按公共/反常标签数判定质量

**模块 2 配色与选材**：从色系池挑出的 2 到 3 套候选色系及理由、选定后的角色色板（主色、签名色、辅色、线稿色）、从材质池选的材质及用在哪个部位、上色提示词（保持线稿不变）、灰度与缩小检查结论、材质色差提醒

**模块 3 插画与海报**：先交角色设定图（三视图和表情）的提示词以保证一致性；再交画风说明、构图方案、场景清单、每张图的出图提示词

**模块 4 表情包与动作**：经典动作库（每个动作写触发情绪、动作过程、和记忆点的互动）、表情包清单（文案用圈层黑话）、短视频动作分镜

**模块 5 故事走向**：世界观最小单元、关系图、口头禅、季度故事线、短视频脚本模板

**模块 6 系列延展**：系列规划（主题、常规款、隐藏款）、换装方案、节点日历、联名方向、升级或裂变判断

**模块 7 产品化与验证**：品类与工艺转译、工艺冲突和改法、打样清单、成本风险、稀缺机制、验证路径和投产门槛

## 收尾

每个模块结束时：
1. 一句话说明这一版改了什么
2. 给出更新后的 IP 档案（只改动的部分可以列 diff，用户要全文时给全文）
3. 问用户是否通过，并推荐下一个模块
