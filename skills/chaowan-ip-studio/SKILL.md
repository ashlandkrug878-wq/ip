# 潮玩 IP 工作室 v2.0 · 工作流第三步

**这一步的起点是一个锁定的形。** 目标是让它从"一张线稿"变成有颜色、有材质、有动作、有故事、有产品线的 IP。分三段，模块可以单独调用，不必全部走完。

## 输入

- **标准输入**：第二步交来的 IP 档案（仓库 `ip-archives/IP档案_<名字>_vN.md`）和锁定线稿（档案"参考图"一节的路径）
- **素材池**：用户在选品板上存的色系池、单色收藏、材质池，是配色和选材的来源（见 `references/pools.md`）
- **对标卡**：仓库 `data/studies/*.json`，第 0 步研究的结果。系列节奏、首发和爆款品类、投产门槛可以参照它的 `product`、`numbers`、`for_skills.studio`，但不照搬具体配色组合
- **没有档案时**（用户直接带着自己的形象来）：先走模块 1 诊断，诊断最后按 `references/bible.md` 补一份 IP 档案
- 用户只有表达、还没有形，建议用 chaowan-ip-form；连表达都没有，建议用 chaowan-ip-lab

## 共同原则

1. **不变量不能动。** IP 档案"不变量"里的表达、核心情绪、原型与轮廓、头身关系、记忆点、五官配置、签名色，任何模块都不能改。用户要求的改动碰到不变量时先指出来；属于造型大改的，建议回到找形，或按 `references/series.md` 判断是版本升级还是裂变成新 IP
2. **不改形。** 上色、选材、渲染、三视图都以锁定线稿为参考图，提示词第一句写"保持参考图的造型、比例和五官完全不变"
3. **先线稿，后配色，再选材。** 配色从素材池的色系里挑；配色定了再从材质池选材
4. **每个模块交付后更新档案。** 新增的色板、动作、口头禅、故事、系列、工艺都写回 IP 档案，版本号加一，记一条变更记录
5. **按载体排优先级。** 主载体是实物潮玩的，先走定型和产品；是短视频或表情包的，先走模块 4 和 5；是海报的，先走模块 3
6. **人负责校准。** 每个模块交付后问一个问题：这一版通过了吗，下一步进哪个模块。不要一次全做完
7. **不写别人的名字。** 出图提示词里不写现有 IP、品牌或艺术家的名字，也不写"像某某"
8. **没看到图不下结论。** 只有文字时，测试项都写"待出图验证"

## 每个模块的交付物

**1 诊断**：区分创意、造型、材质、渲染、执行偏差问题，给证据；外壳与内核判断；五项测试区分实际验证和未验证；保留删改清单和中英文改版提示词。造型要大改时建议回到找形。没有档案时补档案

**2 配色与选材**：从色系池挑 2 到 3 套候选及理由；选定后的角色色板（主色、签名色、辅色、线稿色）；从材质池选的材质及部位；平涂上色提示词（以线稿为参考图）；灰度、缩小、背景检查；材质色差提醒

**3 渲染与三视图**：材质分区说明；成品渲染提示词；正、侧、背三视图提示词；不变量核对结论

**4 插画与海报**：画风说明、构图方案、场景清单、每张图的提示词（以三视图为参考）

**5 表情包与动作**：经典动作库（触发情绪、动作过程、和记忆点的互动）、表情包清单（文案用圈层黑话）、短视频动作分镜

**6 故事走向**：世界观最小单元、关系图、口头禅、季度故事线、短视频脚本模板

**7 系列延展**：系列规划（主题、常规款、隐藏款）、换装方案、节点日历、联名方向、升级或裂变判断

**8 产品化与验证**：品类与工艺转译、工艺冲突和改法、打样清单、成本风险、稀缺机制、验证路径和投产门槛（相信腿不相信嘴：听数据做售卖，听自己做表达）
