## 完整方案卡

### 01 参谋钮 / Counsel Dial

- **原点与转译**：AI 从回答问题走向真实创造与生活协同；转成“旋钮不是替你选，而是把犹豫调到下一步”。
- **表达 / 句式 / 时机**：我不替你决定，只帮你把犹豫拧到可执行；陪伴型；站在“会说话的萌宠 AI”之外，强调动作而非拟真对话。
- **情绪与性格 / 背景**：冷静、可靠、略不耐烦；住在待办事项缝隙里，只给三个档位：先做、再想、放下。
- **经典动作**：双手托空白卡，抬手拧头顶旋钮。
- **外壳与头部**：类人，2 头身，炭灰短身体＋奶油圆头；半垂眼[公共]，三档旋钮冠[反常/原创]，其余五官减法。
- **色彩 / 工艺**：炭灰＋奶油白；签名钴蓝。哑光 PVC，旋钮可做限位转动但首测建议固定件。
- **首品 / 价格 / 系列**：8—10cm PVC 盲盒，89—109 元；系列：今天先做、暂缓一下、果断放下。
- **内容文案**：①“建议已生成，决定还给你。”②“先拧到能动的那格。”③“不是拖延，是正在校准。”
- **中/英提示词**：中文：`中性两头身类人，奶油圆头，头顶嵌一枚钴蓝三档旋钮，半垂眼，炭灰连体服，双手托空白卡，哑光PVC盲盒，全身，暖灰棚拍。` English: `Full-body gender-neutral 2-head-tall humanoid PVC figure, cream round head, one oversized cobalt three-notch dial embedded on the crown, half-lidded eyes, charcoal suit, holding a blank card, matte studio product render.`
- **对标与区别**：最接近 YOYO 的留白感；区别是有嘴、有明确可重复动作，核心是“协助决策”而非情绪容器。
- **设计预评**：闭眼通过（蓝旋钮）；剪影存疑（旋钮俯视更强）；简笔画通过；缩小通过；换皮通过（旋钮结构仍在）。
- **风险**：旋钮易被读成家电；需用内容反复固定“参谋而非控制者”。

### 02 玩钉兽 / Plugbit

- **原点与转译**：从“能用”转向“好玩”，转成一个只有接上有趣模块才启动的生物。
- **表达 / 句式 / 时机**：有用是底线，好玩才让我接上生活；反差型；同侧借势但避开换装娃，以插拔行为作 ID。
- **情绪与性格 / 背景**：顽皮、务实；收集城市里被忽略的小乐趣，插进腹部接口才存档。
- **经典动作**：把黄色小栓“咔嗒”插入腹部。
- **外壳与头部**：原创生物，1.7 头身豆形；圆角连接块头，微斜珊瑚大插栓[反常/原创]，豆豆眼[公共]。
- **色彩 / 工艺**：青绿主色，珊瑚红签名，黄模块；硬 PVC＋头顶软胶件。
- **首品 / 价格 / 系列**：8cm PVC，79—99 元；系列：接上周末、接上勇气、接上荒唐。
- **内容文案**：①“今天插点好玩的。”②“咔嗒，接上了。”③“无聊接口不兼容。”
- **提示词**：中文：`青绿色圆角连接块原创生物，1.7头身，头顶斜插珊瑚红大软栓，腹部黄色接口模块，豆豆眼，哑光PVC全身产品图。` English: `Squat turquoise connector-block creature, diagonal coral soft plug on crown, yellow removable belly connector, tiny eyes, matte PVC collectible, full-body catalog render.`
- **对标与区别**：接近 Bearbrick 的模块化收藏逻辑；区别是非标准画布体型，以“插接动作”而不是涂装为核心。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小通过；换皮通过。
- **风险**：可动插栓涉及小零件与耐久；首版建议大尺寸卡扣或固定造型。

### 03 静响偶 / Hush Beads

- **原点与转译**：Design for Presence 的陶珠、手作与感官连接；转成“轻触头环才会听见细微声音”。
- **表达 / 句式 / 时机**：安静不是没声音，是终于听见自己；允许型；切入成人收藏与感官设计细分。
- **情绪与性格 / 背景**：克制、专注；每颗陶珠记录一次认真听完别人说话的时刻。
- **经典动作**：闭眼轻触最靠近耳边的一颗珠。
- **外壳与头部**：类人，2.4 头身细长；闭眼[公共]，不对称陶珠弧环[反常/原创]，脸部减法。
- **色彩 / 工艺**：灰紫主色，乳白裂纹珠为签名；哑光 PVC＋独立 ABS 珠，首版不可活动。
- **首品 / 价格 / 系列**：12cm PVC，109—139 元；系列：听雨、听杯沿、听停顿。
- **内容文案**：①“我在听，慢慢说。”②“把音量调小，细节会回来。”③“今天不抢答。”
- **提示词**：中文：`细长中性类人偶，闭眼，灰紫连体服，一侧太阳穴升起不对称陶瓷大珠弧环，哑光PVC与缎面陶珠，全身棚拍。` English: `Slender androgynous figure with closed eyes, muted plum suit, asymmetric crescent halo of imperfect ceramic beads rising from one temple, matte PVC, full-body studio render.`
- **对标与区别**：接近 DIMOO 的梦感；区别是不使用云发，以硬质珠环、听觉动作和成人比例建立识别。
- **设计预评**：闭眼通过；剪影通过；简笔画存疑（珠数需简化为 5 颗）；缩小存疑；换皮通过。
- **风险**：当前概念图服装细节偏繁；量产需减到一体衣与 5 珠。

### 04 木涡鼹 / Burl Mole

- **原点与转译**：High Point 的瘿木纹与触觉木材回归；转成额头一圈“想法木涡”。
- **表达 / 句式 / 时机**：我把绕不出去的念头，盘成自己的纹路；自嘲型；用沉稳棕色对抗粉彩软萌拥挤。
- **情绪与性格 / 背景**：慢、固执、踏实；在地下收集树根遇阻后形成的纹理。
- **经典动作**：背手眯眼，用额旋轻轻顶墙。
- **外壳与头部**：动物类人/鼹鼠，梨形 1.8 头身；宽铲爪，实体木涡额旋[反常]，眯眼[公共]。
- **色彩 / 工艺**：可可短绒＋灰褐搪胶脸；签名芥末黄鼻点；额旋仿木纹移印。
- **首品 / 价格 / 系列**：12cm 搪胶毛绒，99—129 元；系列：根结、年轮、雨后木。
- **内容文案**：①“想不通，先盘圆。”②“我有自己的纹路。”③“绕路也算路。”
- **提示词**：中文：`可可短绒梨形鼹鼠，灰褐搪胶脸，额头一枚实体瘿木螺旋，眯眼、芥末黄小鼻，背手，全身搪胶毛绒产品图。` English: `Pear-shaped anthropomorphic mole, cocoa short plush body, taupe vinyl face, one solid burlwood spiral forelock, closed eyes, mustard nose, hands behind back, full-body vinyl-plush product render.`
- **对标与区别**：接近布丁狗的慵懒亲和；区别是鼹鼠宽爪、木涡额旋及“把纠结盘成纹路”。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小通过；换皮通过。
- **风险**：棕色可能显旧；芥末鼻与木纹对比需在货架灯下测试。

### 05 金箔螺 / Gilt Snail

- **原点与转译**：珠母、古铜和手工光泽回归；转成背光而行的慢速收藏家。
- **表达 / 句式 / 时机**：慢没关系，我把光背在身上；反差型；以成年轻奢材料切入非萌宠赛道。
- **情绪与性格 / 背景**：从容、爱打量细节；把沿途的微光压成薄片插在头侧。
- **经典动作**：举镜看一眼，再继续慢慢走。
- **外壳与头部**：动物类人/蜗牛，1.7 头身；珠母扇冠[反常/原创]，触角[公共]，低位螺壳。
- **色彩 / 工艺**：灰紫短绒，珠母乳白＋古金签名；搪胶脸、透明珠光 ABS 扇片，金边喷涂。
- **首品 / 价格 / 系列**：14cm 搪胶毛绒，129—159 元；系列：晨光、旧剧院、月壳。
- **内容文案**：①“迟到的光也算光。”②“慢慢来，反光更完整。”③“我背着自己的高光。”
- **提示词**：中文：`直立灰紫短绒蜗牛，搪胶脸，头侧一枚古金包边的珠母扇冠，低位螺壳，手持无字小镜，全身产品棚拍。` English: `Upright dusty-lilac plush snail, vinyl face, one fan-shaped translucent nacre crown edged in antique gold, low spiral shell, holding a plain mirror, full-body studio product render.`
- **对标与区别**：接近玲娜贝儿的可携带精致感；区别是非狐狸、非粉毛，以珠母硬片与慢速自持为核心。
- **设计预评**：闭眼通过；剪影通过；简笔画存疑；缩小通过；换皮通过。
- **风险**：扇片边缘安全与电镀成本；首版应圆角化并控制片数。

### 06 焊点仔 / Weld Dot

- **原点与转译**：可见焊缝、手工缺陷成为价值；转成把“接缝”公开放在额头。
- **表达 / 句式 / 时机**：接得不平，也不妨碍我继续成形；允许型；明确站在无瑕软萌的对面。
- **情绪与性格 / 背景**：硬气、幽默；每次修复都多一个橙色焊点，只有一个被放在脸上当勋章。
- **经典动作**：插袋挑眉，额头略向前。
- **外壳与头部**：人/类人，2.2 头身；光头[反常]，银色焊线＋橙焊点[原创]，挑眉[公共]。
- **色彩 / 工艺**：炭黑工装、陶土肤色；橙焊点签名。哑光 PVC＋银漆，不做真实伤口。
- **首品 / 价格 / 系列**：10cm PVC，99—129 元；系列：第一次补、粗焊、返工也行。
- **内容文案**：①“接上了，别问平不平。”②“返工不是重来。”③“这一点，焊住了。”
- **提示词**：中文：`光头两头身类人，额顶到眉端一条夸张银色焊缝，末端单颗橙色焊点，炭黑工装，插袋挑眉，哑光PVC全身图。` English: `Bald 2.2-head-tall humanoid, bold silver weld seam from crown to eyebrow ending in one orange weld bead, charcoal workwear, hands in pockets, matte PVC full-body render.`
- **对标与区别**：接近 SKULLPANDA 的酷感；区别是不使用头罩或骨骼，核心是制造痕迹与修复允许。
- **设计预评**：闭眼通过；剪影存疑；简笔画通过；缩小通过；换皮通过。
- **风险**：焊缝可能被误读为伤疤；需保持金属凸点与工业语境。

### 07 化冰怪 / Meltice

- **原点与转译**：Frieze 的融化现代主义与冰晶表面并置；转成一只不断换形但不慌的透明生物。
- **表达 / 句式 / 时机**：变化不是失控，我只是换一种形状；允许型；以冷透明和抽象怪趣对抗绒毛甜萌。
- **情绪与性格 / 背景**：茫然却稳定；它每天都会少一个角、多一个水洼。
- **经典动作**：抱住腰，等头顶那滴落下。
- **外壳与头部**：原创生物，1.8 头身；问号滴冰冠[反常/原创]，宽眼距[反常]，其余减法。
- **色彩 / 工艺**：烟水蓝透明体＋乳白内芯；酸柠檬绿滴尖签名；透明 PVC，底座与脚一体。
- **首品 / 价格 / 系列**：10cm 透明 PVC，109—139 元；系列：将化、半冻、重新结晶。
- **内容文案**：①“我没坏，我在变。”②“今天先化到这里。”③“形状不是承诺。”
- **提示词**：中文：`透明烟水蓝融化生物，头顶一根向前弯成问号的滴冰冠，宽眼距小眼，乳白内芯，抱腰，脚融入水洼底座，透明PVC全身棚拍。` English: `Translucent smoky-aqua melting creature, one long drooping icicle crest curled like a question mark, wide tiny navy eyes, milky core, arms hugging waist, feet merging into puddle base, clear PVC full-body render.`
- **对标与区别**：接近史迪奇的怪物类别；区别是无大耳大嘴，靠液态轮廓、透明材料和“变化许可”识别。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小通过；换皮通过。
- **风险**：透明件气泡、黄变与厚薄色差；需样板测试，概念阶段不宣称工艺成熟。

### 08 拼壳鲎 / Patchshoe

- **原点与转译**：破裂家具、补丁和再利用；转成把修补板缝在古老甲壳上的鲎。
- **表达 / 句式 / 时机**：补丁不是遮丑，是我活过的接口；反差型；非典型动物＋硬壳，远离猫狗兔熊。
- **情绪与性格 / 背景**：警觉、长情；每次退潮都把丢失的壳片换成不同颜色的补片。
- **经典动作**：用尾刺当手杖，壳沿压低看人。
- **外壳与头部**：动物类人/鲎，1.6 头身宽盾形；薄荷绿修补甲片＋三枚大缝钉[原创]，眼藏壳沿下。
- **色彩 / 工艺**：赤陶主色，薄荷绿签名，奶油缝钉；硬 PVC，修补片独立浅浮雕。
- **首品 / 价格 / 系列**：9cm PVC，99—129 元；系列：退潮补、城市铁皮补、夜光海玻璃补。
- **内容文案**：①“这不是裂，是接口。”②“旧壳也能继续上岸。”③“补过，所以更知道哪里要护住。”
- **提示词**：中文：`直立鲎角色，宽盾形赤陶硬壳，壳顶一块薄荷绿修补甲片，以三枚奶油大缝钉连接，小眼藏在壳沿，尾刺作手杖，哑光PVC全身图。` English: `Anthropomorphic horseshoe crab with wide terracotta shield shell, one mint repair plate joined by three oversized cream stitches, tiny eyes under rim, tail used as walking cane, matte PVC full-body product render.`
- **对标与区别**：接近 LABUBU 的怪趣收藏性；区别是无牙无尖耳，以鲎盾形、修补甲片和低重心识别。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小通过；换皮通过。
- **风险**：鲎真实形态可能引起甲壳虫联想；需维持圆角盾面和低细节腹部。

### 09 倦肢椅 / Off-Duty Chair

- **原点与转译**：Frieze 对屏幕时代身体疲惫与肢体碎片的关注；转成“椅子自己也累瘫”。
- **表达 / 句式 / 时机**：身体先下班，也算完成今天；自嘲型；面向办公、通勤和久坐圈层。
- **情绪与性格 / 背景**：疲惫、无攻击性、诚实；白天托住别人，晚上把自己的肩放下来。
- **经典动作**：双臂垂地，拎着却不用的靠垫。
- **外壳与头部**：拟物/椅子生物，2 头身；圆角椅背头＋下垂双肩瓣[反常/原创]，半垂眼[公共]，座垫为身体功能件。
- **色彩 / 工艺**：深甜菜红短绒；雾蓝靠垫签名；全毛绒、刺绣眼、内置软板保持椅背轮廓。
- **首品 / 价格 / 系列**：15cm 毛绒挂件，89—119 元；系列：会议后、通勤后、社交后。
- **内容文案**：①“身体已读，不回。”②“今天托不住了。”③“靠垫带了，没力气靠。”
- **提示词**：中文：`拟人椅子毛绒角色，深甜菜红圆角椅背头，顶部两枚不对称下垂软肩瓣，半垂眼，超长垂臂，雾蓝靠垫，全身短绒产品棚拍。` English: `Anthropomorphic plush chair creature, deep beet-red rounded chair-back head, two asymmetric drooping padded shoulder lobes, sleepy eyes, very long hanging arms, pale-blue cushion, full-body studio product render.`
- **对标与区别**：接近蛋黄哥的疲惫自嘲；区别是直立家具轮廓、肩部下垂和“托住别人”的职业关系。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小存疑（长臂需保留）；换皮通过。
- **风险**：可能被误读成狗耳；内容与包装需明确“肩膀/椅背”，避免动物化。
