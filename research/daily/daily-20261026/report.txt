## 方案卡

### 01 省算仔
- **来源/表达/句式**：理性消费与促销策略长期背景；“省下来的不是面子，是决定权”｜反差型。
- **性格背景/动作**：精明、克制、嘴硬；替冲动购物的人多算三秒；手指拨小算盘。
- **外壳头部**：类人2.1头身；倾斜圆形减号印章冠[反常]，一眯一睁眼[反常]，短嘴。
- **颜色工艺产品**：酒红＋灰蓝，荧光黄签名扣；哑光PVC，9cm，¥79–99。
- **系列**：凑单夜 / 退货期 / 券后价。**文案**：我不是抠，是有选择 / 等一下，我再算一遍 / 省到就是赚到决定权。
- **近似区别**：接近潮流人形盲盒，但印章冠与心算动作固定，不以服装成立。
- **设计预评**：闭眼通过；剪影通过；简笔画通过；缩小通过；换皮通过。
- **风险**：现图街头潮人感过强，下一版应减发量、去算盘实物，保留手势。
- **中英提示词**：中：倾斜减号印章冠、异向眼、心算手势的2.1头身类人硬PVC。EN: Original 2.1-head-tall vinyl figure with one tilted minus-stamp crown, asymmetric eyes and mental-calculation gesture.

### 02 断讯鼹
- **来源/表达/句式**：数字排毒长期背景；“不回消息时，我在回到自己”｜允许型。
- **性格背景/动作**：安静、边界感强；每天关机十五分钟钻回自己的洞；手机反扣胸前。
- **外壳头部**：鼹鼠类人1.8头身；关闭拨片冠[反常]，闭线眼、长扁鼻。
- **颜色工艺产品**：炭黑＋奶白，薄荷绿签名；搪胶脸短绒身，12cm，¥79–109。
- **系列**：勿扰 / 飞行模式 / 已读不回。**文案**：我先离线一下 / 没失联，在充自己 / 今天不接收世界。
- **近似区别**：接近圆胖动物毛绒，但拨片冠和反扣动作形成独立ID。
- **设计预评**：五项均通过；缩小时薄荷拨片仍醒目。
- **风险**：现图手机过于写实，可换成无屏幕灰色板，避免品牌联想。
- **提示词**：中：黑色小鼹鼠，关闭拨片头冠，闭眼，反扣无标识手机，搪胶毛绒。EN: Original black mole plush character with an OFF toggle crown, closed eyes and a face-down unbranded device.

### 03 圈座团
- **来源/表达/句式**：10月文化报道中的conversation pit与亲密观看；“靠近一点，不必立刻说话”｜陪伴型。
- **性格背景/动作**：包容、慢热；它把空位留给不擅长开场的人；双手向内邀请。
- **外壳头部**：拟物生物1.5头身；下沉环座整体轮廓[反常]，脸在前缘。
- **颜色工艺产品**：焦糖橙＋深青；短绒毛绒，11cm，¥89–119。
- **系列**：两人坑 / 沉默局 / 深夜围坐。**文案**：坐近点就好 / 不说也算见面 / 中间还空一个位置。
- **近似区别**：不像常见团子或食物，以“可围坐的空心结构”为核心。
- **设计预评**：闭眼、剪影、缩小通过；简笔画通过；换皮通过。
- **风险**：现图更像真实家具；角色版需缩小内坑、增加头身关系，不能宣传真实承重。
- **提示词**：中：圆形下沉会客坑拟物生物，环形靠背头，焦糖橙与深青短绒。EN: Original conversation-pit creature with a circular recessed seat head, caramel velvet and deep teal.

### 04 皱幕怪
- **来源/表达/句式**：Art Basel Paris近期出现揉皱画布与抗议表达；“被揉皱，也不等于撤回”｜反差型。
- **性格背景/动作**：倔强、直白；把被否定的话重新撑开；双臂拉住画布两角。
- **外壳头部**：怪兽精灵2头身；方形皱幕头[反常]＋单道橙折痕。
- **颜色工艺产品**：米白＋雾紫，签名亮橙；硬PVC布纹，9cm，¥79–99。
- **系列**：撤稿 / 退场 / 再展开。**文案**：皱了，没撤 / 这句我还留着 / 别替我抚平。
- **近似区别**：不靠尖牙怪趣，整张皱幕就是面部与表达。
- **设计预评**：五项均通过。
- **风险**：四角结构可能锋利；需大圆角，折痕只保留一条。
- **提示词**：中：方形皱画布头怪兽，单道橙色斜折痕，双手撑开，硬PVC。EN: Original creature with a crumpled square canvas head, one orange diagonal crease, stretching itself open.

### 05 叠声人
- **来源/表达/句式**：近期展会巨型文字与公共表达；“说不完整，也要留下这一层”｜允许型。
- **性格背景/动作**：冷静、执拗；把没说完的话叠成无字块；胸前发声条翻起。
- **外壳头部**：中性类人2.3头身；三层错位无字块冠[反常]，直视眼，小嘴。
- **颜色工艺产品**：骨白＋群青＋朱红；硬PVC，9cm，¥89–109。
- **系列**：低声 / 重音 / 消音。**文案**：这一层先留下 / 没说完，不等于没说 / 音量小，态度没小。
- **近似区别**：接近未来感人形，但不使用头罩，以字块层级和胸前声条为功能件。
- **设计预评**：闭眼通过；剪影通过；简笔画存疑；缩小通过；换皮通过。
- **风险**：现图发型和大眼过于精致，需删除发丝、缩眼、强化几何头。
- **提示词**：中：三层错位无字块冠、胸前翻转发声条、骨白群青朱红中性人形PVC。EN: Original androgynous vinyl figure with three offset blank text blocks and a flip-up voice tab.

### 06 光鬃獾
- **来源/表达/句式**：Design Miami Paris毛发生物灯；“我不负责耀眼，只负责把你照到”｜陪伴型。
- **性格背景/动作**：疲惫、可靠；夜里收集别人没用完的微光；抱暖光球。
- **外壳头部**：蜜獾2头身；单圈发光马毛鬃冠[反常]，半垂眼。
- **颜色工艺产品**：黑白＋琥珀金；搪胶头短绒身、光纤模拟鬃，12cm，¥109–139。
- **系列**：床头 / 巷口 / 末班灯。**文案**：亮到你就够了 / 借我一点余光 / 今晚不必全黑。
- **近似区别**：非熊猫头罩，蜜獾面纹与环鬃/抱光动作构成区别。
- **设计预评**：闭眼、剪影、缩小通过；简笔画存疑；换皮通过。
- **风险**：现图写实度高、光效不可直接量产；首版用反光丝而非电子灯。
- **提示词**：中：黑白小蜜獾，柔软环状光鬃，抱琥珀光球，搪胶毛绒。EN: Original honey badger with a soft circular luminous mane, holding an amber orb, vinyl-plush toy.

### 07 算椅
- **来源/表达/句式**：Design Miami Paris数字生成不锈钢椅获当代设计奖；“算出来的形，也能坐进生活”｜反差型。
- **性格背景/动作**：理性、好奇；从算法里走出来寻找真实坐痕；抬腿行走。
- **外壳头部**：拟物椅生物1.8头身；连续曲线椅背头[反常]，座面圆肚。
- **颜色工艺产品**：拉丝银＋电紫；PVC金属漆，9cm，¥89–119。
- **系列**：参数偏差 / 人体工学 / 坐痕。**文案**：算得出，坐不准 / 参数齐了，人呢 / 我先走去找生活。
- **近似区别**：不像固定比例熊形画布，椅背结构、座面身体和步态不可替换。
- **设计预评**：闭眼、剪影、简笔画、缩小、换皮全通过。
- **风险**：镜面掉漆和指纹明显；建议主体改拉丝银。图中脸略大，下一版缩至椅背1/2。
- **提示词**：中：连续弯曲椅背头、座面圆肚、迈步的银色数字生成椅生物。EN: Original walking chair-creature with one continuous curved backrest head, rounded seat belly, brushed silver and electric violet.

### 08 漂纤兽
- **来源/表达/句式**：10月纤维展讨论传统迁移与扎根；“换一片土地，不等于拔掉来处”｜允许型。
- **性格背景/动作**：坚韧、寡言；把旧土颜色带到新地方重新扎根；握住根线。
- **外壳头部**：原创生物1.7头身；跨头纤维桥冠[反常]，窄眼，梨形身体。
- **颜色工艺产品**：土红→海蓝，米白底；搪胶脸粗纤维身，12cm，¥99–129。
- **系列**：越海 / 换土 / 新根。**文案**：我只是换土 / 根还在手里 / 走远了，也没丢来处。
- **近似区别**：不做动物头套或云发，纤维桥有明确迁移方向。
- **设计预评**：闭眼、剪影、换皮通过；简笔画存疑；缩小存疑。
- **风险**：现图像羊，且冠过细乱；下一版去耳、把纤维桥简化成三股粗绳。
- **提示词**：中：无动物耳原创梨形生物，头顶三股粗纤维桥从土红过渡到海蓝。EN: Original earless pear-shaped creature with a three-strand fibre bridge transitioning from earth red to ocean blue.

### 09 锚睡鱼
- **来源/表达/句式**：Z世代确定性与情绪锚点长期背景；“今天不远航，只先把自己停稳”｜允许型。
- **性格背景/动作**：困倦、谨慎；把尾巴抱紧，等情绪海浪过去；抱尾静立。
- **外壳头部**：深海鱼1.6头身；圆钝倒U软锚冠[反常]，半闭眼小圆嘴。
- **颜色工艺产品**：深海蓝＋珊瑚红，米白腹点；搪胶冠短绒身，12cm，¥79–109。
- **系列**：浅停 / 潮退 / 安全港。**文案**：先停稳再说 / 今天不出港 / 浪过去我再动。
- **近似区别**：不同于厚唇半鱼人，以软锚冠、抱尾和困眼构成表达。
- **设计预评**：闭眼、剪影、缩小、换皮通过；简笔画通过。
- **风险**：现图锚形接近提手，需让两端向外形成软锚语义；鱼鳍不宜过多。
- **提示词**：中：深海蓝小鱼，圆钝倒U软锚冠，抱住尾巴，困眼，搪胶毛绒。EN: Original deep-sea fish plush with a rounded soft anchor-shaped crown, sleepy eyes and tail held in both arms.
